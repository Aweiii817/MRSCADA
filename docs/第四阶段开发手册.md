## 开篇：预备知识——第四阶段的三个核心概念

### 1. 什么是报警引擎？为什么它是最重要的安全功能？

想象一个化工反应釜：正常温度 150°C，最高允许 200°C。如果温度失控冲到 250°C，反应釜会爆炸。操作员不可能 24 小时盯着屏幕，所以系统必须**主动发现问题并提醒**。

报警引擎就是干这个的：**持续监测数据，一旦某个值超出安全范围，立刻发出报警**。

在真实工厂里，报警系统的优先级高于一切。国家标准（如 GB/T 28808《控制室人机工程设计》系列、IEC 62682）对报警管理有专门规范，因为历史上多起重大化工事故的直接原因就是"报警失效"或"报警风暴"（一次来几百条报警，操作员根本看不过来）。

报警引擎要做的事：

```
传感器数据 → 报警引擎持续评估 → 超限？ → 生成报警事件 → 通知操作员
                                          ↓
                                    操作员确认/处理 → 数据恢复 → 报警恢复
```

**报警的几种类型（本项目都实现）：**

| 类型              | 触发条件     | 例子               |
| --------------- | -------- | ---------------- |
| 高限报警（High）      | 值 > 上限   | 温度 > 180°C       |
| 高高限报警（HighHigh） | 值 > 更高上限 | 温度 > 200°C（更紧急）  |
| 低限报警（Low）       | 值 < 下限   | 液位 < 10%         |
| 变化率报警（Rate）     | 单位时间变化过快 | 压力 1 秒内升 0.5 MPa |
| 数字量报警（Digital）  | 状态变位     | 急停按钮被按下          |
| 通信故障报警          | 设备离线     | PLC 失去连接         |

**报警优先级（本项目的四级）：**

```
CRITICAL  —— 最高，需要立即停机（高高限、急停）
HIGH      —— 高，需要尽快处理（高限、通信断开）
MEDIUM    —— 中，需要注意（液位偏低）
LOW       —— 低，记录即可（轻微偏差）
```

### 2. 报警状态机（理解报警生命周期的关键）

一条报警不是"出现就消失"这么简单，它有一整套生命周期。这就是状态机：

```
                    ┌─────────────────────────────┐
                    │          正常 (NORMAL)        │
                    └──────────────┬──────────────┘
                             数值超限
                                   │
                                   ▼
                    ┌─────────────────────────────┐
                    │       报警产生 (ACTIVE)       │
                    │  "温度高高限，请处理！"        │
                    └──────────────┬──────────────┘
                             操作员确认
                                   │
                                   ▼
                    ┌─────────────────────────────┐
                    │    报警确认 (ACKNOWLEDGED)    │
                    │  "已收到，正在处理"           │
                    └──────────────┬──────────────┘
                             数值恢复正常
                                   │
                                   ▼
                    ┌─────────────────────────────┐
                    │   恢复待确认 (CLEARED_UNACK)  │
                    │  "数值已恢复，请确认解除"      │
                    └──────────────┬──────────────┘
                             操作员确认恢复
                                   │
                                   ▼
                    ┌─────────────────────────────┐
                    │          正常 (NORMAL)        │
                    └─────────────────────────────┘
```

**为什么要分"报警确认"和"恢复确认"两步？**

这是工业报警管理的核心规范。举例：

- 温度超限了 → 报警产生 → 操作员点"确认"（表示"我知道了，在处理"）
- 温度恢复正常了 → 报警进入"恢复待确认" → 操作员再点"确认恢复"（表示"我确认这个问题已经解决了"）

如果报警自动消失而不需要确认，操作员可能根本不知道曾经发生过报警。分两步确保**每条报警都有人负责、有始有终**。

### 3. 什么是配方（Recipe）？为什么化工需要配方管理？

配方 = 生产一个产品所需的完整工艺参数方案。同一个反应釜可以生产不同产品，每个产品对应一套配方：

```json
{
  "recipe_id": "RCP-001",
  "product_name": "聚丙烯酸酯 A型",
  "stages": [
    {"stage": "进料",  "level_target": 80,  "duration": 300},
    {"stage": "加热",  "temp_target": 150, "rate_limit": 5},
    {"stage": "恒温",  "temp_target": 150, "duration": 3600},
    {"stage": "冷却",  "temp_target": 50},
    {"stage": "出料",  "level_target": 5}
  ]
}
```

为什么要配方管理而不是硬编码？

- 不同产品工艺参数不同（A 型要 150°C，B 型要 180°C）
- 工程师经常调整工艺（调温度、调时间）
- 需要版本管理（改了配方要能追溯谁改的、改了什么）
- 配方要"下发"给 PLC/仿真器执行

### 4. 什么是 HTML 报表？为什么要用它？

报表系统输出生产数据汇总。生成方式对比：

| 方式             | 优点                                    | 缺点         |
| -------------- | ------------------------------------- | ---------- |
| 手写 QPainter 画  | 灵活                                    | 代码量巨大，改版式难 |
| **HTML → PDF** | HTML 排版简单，Qt 内置 QTextDocument 直接转 PDF | 复杂图表不好画    |
| 第三方库（QXlsx等）   | Excel 原生格式                            | 额外依赖       |

我们选 **HTML → PDF** 方案：

1. 用字符串拼接 HTML（表格排版，和写网页一样）
2. 用 `QTextDocument::setHtml()` 加载 HTML
3. 用 `QPrinter` 把文档打印成 PDF（或直接打印到纸）

### 5. 第四阶段目标与验收标准

完成后你应该能：

1. **报警引擎运行**：温度超过 180°C 自动产生报警，状态栏/报警页红灯闪烁
2. **报警确认**：点"确认"后报警状态变化，点"确认恢复"后报警消失
3. **报警历史**：查询过去的所有报警记录（含产生/确认/恢复时间）
4. **配方编辑**：新建/修改/保存配方（JSON 持久化）
5. **配方执行**：选定配方下发执行，仿真引擎按配方参数运行
6. **日报生成**：一键生成当天生产数据 HTML 报表并导出 PDF
7. **日志查看**：界面里查看系统运行日志

## 第一章：写报警引擎（AlarmEngine）

### 1.0 先想清楚报警引擎的数据结构

写代码前，先定义三个核心数据结构：

1. **AlarmRule（报警规则）**——"什么情况下报警"，是静态配置，从 JSON 加载
2. **AlarmEvent（报警事件）**——"一次具体的报警"，是运行时动态产生的
3. **AlarmEngine（报警引擎）**——把规则和实时数据比对，产生/更新事件

它们的关系：

```
AlarmRule（规则）          AlarmEvent（事件）
"温度 > 180°C 报警"  ───评估──→  "10:30:15 温度达到 185°C，高高限报警"
（一份规则，静态）             （每次触发产生一条，动态）
```

**规则可以复用，事件是历史的记录。** 一条规则在一天内可能触发 10 次报警，每次产生一条独立的 AlarmEvent。

### 1.1 写 AlarmRule.h（报警规则）

**文件路径：** `D:\QtProject\UCS\src\core\alarm\AlarmRule.h`

```cpp
// ============================================================
// AlarmRule.h — 报警规则定义
//
// 报警规则描述"什么情况下算报警"，是静态配置。
// 从 JSON 文件加载，比如：
//   {"tag":"TE-101","type":"high","limit":180,"priority":2}
// 意思是：TE-101 的值超过 180 时，产生高优先级报警
// ============================================================
#pragma once

#include <string>
#include <cstdint>

/// @brief 报警类型
enum class AlarmType : uint8_t
{
    HIGH       = 0,   // 高限：值 > limit
    HIGH_HIGH  = 1,   // 高高限：值 > limit（更紧急）
    LOW        = 2,   // 低限：值 < limit
    LOW_LOW    = 3,   // 低低限：值 < limit（更紧急）
    RATE_UP    = 4,   // 上升变化率：单位时间内上升超过 limit
    RATE_DOWN  = 5,   // 下降变化率
    DIGITAL_ON = 6,   // 数字量变 1（如急停按下）
    DIGITAL_OFF= 7,   // 数字量变 0
    COMM_FAULT = 8    // 通信故障（设备离线）
};

/// @brief 报警优先级
enum class AlarmPriority : uint8_t
{
    CRITICAL = 0,   // 危急：需要立即停机（高高限、急停）
    HIGH     = 1,   // 高：需要尽快处理（高限、通信断开）
    MEDIUM   = 2,   // 中：需要注意（液位偏低）
    LOW      = 3    // 低：记录即可（轻微偏差）
};

/// @brief 报警规则（静态配置）
struct AlarmRule
{
    std::string rule_id;         // 规则唯一标识，如 "ALM-001"
    std::string tag_name;        // 监测的位号，如 "TE-101"
    AlarmType type;              // 报警类型
    double limit = 0.0;          // 限值（高/低限、变化率阈值）
    double hysteresis = 1.0;     // 滞后带（防止抖动，见下方说明）
    AlarmPriority priority = AlarmPriority::MEDIUM;  // 优先级
    std::string message;         // 报警描述，如 "反应釜温度高高限"
    bool enabled = true;         // 是否启用
};

/// @brief 报警状态（状态机）
enum class AlarmState : uint8_t
{
    INACTIVE      = 0,   // 未激活（正常）
    ACTIVE        = 1,   // 已产生（等待确认）
    ACKNOWLEDGED  = 2,   // 已确认（等待恢复）
    CLEARED_UNACK = 3    // 已恢复未确认（等待恢复确认）
};
```

**什么是滞后带（hysteresis）？为什么需要它？**

想象温度限值是 180°C，温度在 179.9°C 和 180.1°C 之间来回跳动。如果没有滞后带：

- 179.9 → 没报警
- 180.1 → 报警！
- 179.9 → 报警消失
- 180.1 → 又报警！
- ...每 100ms 报警开关一次，产生报警风暴

加滞后带（比如 2°C）：

- 超过 180 才报警
- 要降到 178 以下才恢复（180 - 2）
- 中间的抖动被"吸收"了

这是工业报警的基本功——**没有滞后带的报警系统是废的**。

### 1.2 写 AlarmEvent.h（报警事件）

**文件路径：** `D:\QtProject\UCS\src\core\alarm\AlarmEvent.h`

```cpp
// ============================================================
// AlarmEvent.h — 报警事件定义
//
// 报警事件是"一次具体的报警"，运行时动态产生。
// 记录报警的完整生命周期：产生时间、确认时间、恢复时间。
// ============================================================
#pragma once

#include "AlarmRule.h"
#include <string>
#include <cstdint>

/// @brief 报警事件（动态数据）
struct AlarmEvent
{
    std::string event_id;        // 事件唯一 ID（用 Utility::generateId 生成）
    std::string rule_id;         // 关联的规则 ID
    std::string tag_name;        // 触发的位号
    std::string message;         // 报警描述
    AlarmType type;              // 报警类型
    AlarmPriority priority;      // 优先级
    AlarmState state;            // 当前状态

    double trigger_value;        // 触发时的数值（如 185.3°C）
    double limit_value;          // 限值（如 180.0°C）

    uint64_t trigger_time_ms;    // 报警产生时间（毫秒时间戳）
    uint64_t ack_time_ms = 0;    // 确认时间（0 = 未确认）
    uint64_t clear_time_ms = 0;  // 数值恢复时间（0 = 未恢复）
    uint64_t ack_clear_time_ms = 0;  // 恢复确认时间（0 = 未确认）

    /// @brief 是否还在"激活中"（还没走完整个生命周期）
    bool isActive() const
    {
        return state == AlarmState::ACTIVE ||
               state == AlarmState::ACKNOWLEDGED;
    }

    /// @brief 是否已彻底结束
    bool isClosed() const
    {
        return state == AlarmState::INACTIVE;
    }
};
```

### 1.3 写 AlarmEngine.h（报警引擎核心）

**文件路径：** `D:\QtProject\UCS\src\core\alarm\AlarmEngine.h`

```cpp
// ============================================================
// AlarmEngine.h — 报警引擎
//
// 这是整个报警系统的核心。它的工作循环：
//
//   1. 定时器每隔 check_interval_ms 触发一次
//   2. 遍历所有启用的报警规则
//   3. 从 RealTimeDB 读取对应测点的当前值
//   4. 判断是否满足报警条件（考虑滞后带）
//   5. 根据状态机更新或创建报警事件
//   6. 发出信号通知 UI
//
// 单例模式：整个系统只有一个报警引擎。
// ============================================================
#pragma once

#include <QObject>
#include <QTimer>
#include <vector>
#include <unordered_map>
#include <memory>
#include "AlarmRule.h"
#include "AlarmEvent.h"

class AlarmEngine : public QObject
{
    Q_OBJECT

public:
    static AlarmEngine& instance();

    /// @brief 从 JSON 字符串加载报警规则
    /// @return 加载的规则数量
    size_t loadRulesFromJson(const std::string& json_str);

    /// @brief 启动报警评估循环
    /// @param interval_ms 评估间隔（毫秒），默认 200ms
    void start(int interval_ms = 200);

    /// @brief 停止评估
    void stop();

    /// @brief 确认一条报警（操作员点击"确认"）
    bool acknowledge(const std::string& event_id);

    /// @brief 确认报警恢复（操作员点击"确认恢复"）
    bool acknowledgeClear(const std::string& event_id);

    /// @brief 获取当前激活中的报警列表
    std::vector<AlarmEvent> getActiveAlarms() const;

    /// @brief 获取所有报警事件（含已恢复的，用于历史查询）
    std::vector<AlarmEvent> getAllEvents() const;

    /// @brief 当前激活的报警数量
    int activeAlarmCount() const;

signals:
    /// @brief 新报警产生
    void alarmActivated(const QString& event_id);

    /// @brief 报警被确认
    void alarmAcknowledged(const QString& event_id);

    /// @brief 报警已恢复（数值恢复正常）
    void alarmCleared(const QString& event_id);

    /// @brief 报警彻底关闭（恢复确认完成）
    void alarmClosed(const QString& event_id);

    /// @brief 激活报警数变化（UI 显示角标用）
    void activeAlarmCountChanged(int count);

private slots:
    /// @brief 定时评估
    void onEvaluateTick();

private:
    AlarmEngine();
    ~AlarmEngine() override;

    /// @brief 评估单条规则，处理可能的报警产生/恢复
    void evaluateRule(const AlarmRule& rule);

    /// @brief 判断某测点当前值是否触发报警
    /// @param rule 规则
    /// @param value 当前值
    /// @return true 触发报警
    bool isTriggered(const AlarmRule& rule, double value) const;

    /// @brief 查找该规则下"激活中"的报警事件（用于避免重复产生）
    AlarmEvent* findActiveEventByRule(const std::string& rule_id);

    QTimer* m_timer = nullptr;
    std::vector<AlarmRule> m_rules;           // 所有规则
    std::vector<AlarmEvent> m_events;         // 所有事件（含历史）
    std::unordered_map<std::string, AlarmEvent*> m_active_by_rule;  // 快速查找激活事件

    bool m_running = false;
};
```

### 1.4 写 AlarmEngine.cpp（核心逻辑）

**文件路径：** `D:\QtProject\UCS\src\core\alarm\AlarmEngine.cpp`

这是整个阶段最核心的一段代码，重点理解**状态机转换逻辑**。

```cpp
// ============================================================
// AlarmEngine.cpp — 报警引擎实现
// ============================================================
#include "AlarmEngine.h"
#include "core/rtdb/RealTimeDB.h"
#include "common/Logger.h"
#include "common/Utility.h"
#include <nlohmann/json.hpp>
#include <QDateTime>
#include <cmath>

using Json = nlohmann::json;

AlarmEngine& AlarmEngine::instance()
{
    static AlarmEngine inst;
    return inst;
}

AlarmEngine::AlarmEngine()
    : QObject(nullptr)
{
}

AlarmEngine::~AlarmEngine()
{
    stop();
}

size_t AlarmEngine::loadRulesFromJson(const std::string& json_str)
{
    m_rules.clear();

    try {
        Json j = Json::parse(json_str);
        if (!j.contains("rules") || !j["rules"].is_array()) {
            LOG_ERROR("AlarmEngine: JSON missing 'rules' array");
            return 0;
        }

        for (const auto& item : j["rules"]) {
            AlarmRule rule;
            rule.rule_id    = item.value("rule_id", "");
            rule.tag_name   = item.value("tag_name", "");
            rule.type       = static_cast<AlarmType>(item.value("type", 0));
            rule.limit      = item.value("limit", 0.0);
            rule.hysteresis = item.value("hysteresis", 1.0);
            rule.priority   = static_cast<AlarmPriority>(item.value("priority", 2));
            rule.message    = item.value("message", "");
            rule.enabled    = item.value("enabled", true);

            if (rule.rule_id.empty() || rule.tag_name.empty()) continue;

            m_rules.push_back(rule);
        }

        LOG_INFO("AlarmEngine: loaded {} rules", m_rules.size());
    } catch (const std::exception& e) {
        LOG_ERROR("AlarmEngine: JSON parse failed - {}", e.what());
    }

    return m_rules.size();
}

void AlarmEngine::start(int interval_ms)
{
    if (m_running) return;

    if (!m_timer) {
        m_timer = new QTimer(this);
        connect(m_timer, &QTimer::timeout,
                this, &AlarmEngine::onEvaluateTick);
    }
    m_timer->start(interval_ms);
    m_running = true;

    LOG_INFO("AlarmEngine: started (interval={}ms)", interval_ms);
}

void AlarmEngine::stop()
{
    if (m_timer) m_timer->stop();
    m_running = false;
}

void AlarmEngine::onEvaluateTick()
{
    // 每个评估周期，遍历所有规则
    for (const auto& rule : m_rules) {
        if (!rule.enabled) continue;
        evaluateRule(rule);
    }
}

void AlarmEngine::evaluateRule(const AlarmRule& rule)
{
    // ---- 1. 读取当前值 ----
    TagDataPoint point;
    if (!RealTimeDB::instance().getTagValue(rule.tag_name, point)) {
        return;  // 还没数据，跳过
    }

    // ---- 2. 特殊处理：通信故障报警 ----
    // 数据质量 BAD 说明设备离线/传感器故障
    if (rule.type == AlarmType::COMM_FAULT) {
        bool fault = (point.quality == Quality::BAD);
        if (fault) {
            // 通信故障 → 触发报警
            if (!findActiveEventByRule(rule.rule_id)) {
                AlarmEvent ev;
                ev.event_id = Utility::generateId();
                ev.rule_id = rule.rule_id;
                ev.tag_name = rule.tag_name;
                ev.message = rule.message.empty()
                           ? "通信故障：" + rule.tag_name : rule.message;
                ev.type = rule.type;
                ev.priority = rule.priority;
                ev.state = AlarmState::ACTIVE;
                ev.trigger_value = point.scaled_value;
                ev.limit_value = rule.limit;
                ev.trigger_time_ms = QDateTime::currentMSecsSinceEpoch();

                m_events.push_back(ev);
                m_active_by_rule[rule.rule_id] = &m_events.back();

                emit alarmActivated(QString::fromStdString(ev.event_id));
                emit activeAlarmCountChanged(activeAlarmCount());
                LOG_WARN("AlarmEngine: COMM_FAULT on {}", rule.tag_name);
            }
        } else {
            // 通信恢复 → 恢复报警
            AlarmEvent* ev = findActiveEventByRule(rule.rule_id);
            if (ev && ev->state != AlarmState::CLEARED_UNACK) {
                ev->state = AlarmState::CLEARED_UNACK;
                ev->clear_time_ms = QDateTime::currentMSecsSinceEpoch();
                emit alarmCleared(QString::fromStdString(ev->event_id));
            }
        }
        return;
    }

    // ---- 3. 判断是否触发 ----
    bool triggered = isTriggered(rule, point.scaled_value);

    // 查找该规则下"激活中"的事件
    AlarmEvent* active_ev = findActiveEventByRule(rule.rule_id);

    if (triggered) {
        // ---- 报警条件满足 ----
        if (!active_ev) {
            // 🎯 没有激活事件 → 创建新报警
            AlarmEvent ev;
            ev.event_id = Utility::generateId();
            ev.rule_id = rule.rule_id;
            ev.tag_name = rule.tag_name;
            ev.message = rule.message.empty()
                       ? rule.tag_name + " 报警" : rule.message;
            ev.type = rule.type;
            ev.priority = rule.priority;
            ev.state = AlarmState::ACTIVE;
            ev.trigger_value = point.scaled_value;
            ev.limit_value = rule.limit;
            ev.trigger_time_ms = QDateTime::currentMSecsSinceEpoch();

            m_events.push_back(ev);
            m_active_by_rule[rule.rule_id] = &m_events.back();

            emit alarmActivated(QString::fromStdString(ev.event_id));
            emit activeAlarmCountChanged(activeAlarmCount());

            LOG_WARN("AlarmEngine: {} triggered on {} (value={:.1f}, limit={:.1f})",
                     ev.message, rule.tag_name, point.scaled_value, rule.limit);
        }
        // 已有激活事件 → 什么都不做（避免重复报警）
    } else {
        // ---- 报警条件不满足 ----
        if (active_ev && active_ev->state != AlarmState::CLEARED_UNACK) {
            // 🎯 有激活事件但现在条件不满足了 → 进入"恢复待确认"
            active_ev->state = AlarmState::CLEARED_UNACK;
            active_ev->clear_time_ms = QDateTime::currentMSecsSinceEpoch();
            emit alarmCleared(QString::fromStdString(active_ev->event_id));
            LOG_INFO("AlarmEngine: {} cleared on {}", active_ev->message,
                     active_ev->tag_name);
        }
    }
}

bool AlarmEngine::isTriggered(const AlarmRule& rule, double value) const
{
    switch (rule.type) {
    case AlarmType::HIGH:
        return value > rule.limit;
    case AlarmType::HIGH_HIGH:
        return value > rule.limit;
    case AlarmType::LOW:
        return value < rule.limit;
    case AlarmType::LOW_LOW:
        return value < rule.limit;
    case AlarmType::DIGITAL_ON:
        return value > 0.5;   // 数字量为 1
    case AlarmType::DIGITAL_OFF:
        return value <= 0.5;  // 数字量为 0
    default:
        // 变化率报警需要历史数据，简化处理：本阶段暂不实现
        return false;
    }
}

AlarmEvent* AlarmEngine::findActiveEventByRule(const std::string& rule_id)
{
    auto it = m_active_by_rule.find(rule_id);
    if (it != m_active_by_rule.end()) {
        // 注意：如果事件已经关闭，从激活表移除
        if (it->second->isClosed()) {
            m_active_by_rule.erase(it);
            return nullptr;
        }
        return it->second;
    }
    return nullptr;
}

bool AlarmEngine::acknowledge(const std::string& event_id)
{
    // 🎯 遍历查找事件（事件数量不多，线性查找足够）
    // 生产环境可改用哈希表，学习阶段保持简单
    for (auto& ev : m_events) {
        if (ev.event_id == event_id) {
            if (ev.state == AlarmState::ACTIVE) {
                ev.state = AlarmState::ACKNOWLEDGED;
                ev.ack_time_ms = QDateTime::currentMSecsSinceEpoch();
                emit alarmAcknowledged(QString::fromStdString(event_id));
                LOG_INFO("AlarmEngine: acknowledged {}", event_id);
                return true;
            }
            break;
        }
    }
    return false;
}

bool AlarmEngine::acknowledgeClear(const std::string& event_id)
{
    for (auto& ev : m_events) {
        if (ev.event_id == event_id) {
            if (ev.state == AlarmState::CLEARED_UNACK) {
                // 🎯 恢复确认 → 事件彻底关闭
                ev.state = AlarmState::INACTIVE;
                ev.ack_clear_time_ms = QDateTime::currentMSecsSinceEpoch();

                // 从激活表移除
                m_active_by_rule.erase(ev.rule_id);

                emit alarmClosed(QString::fromStdString(event_id));
                emit activeAlarmCountChanged(activeAlarmCount());
                LOG_INFO("AlarmEngine: cleared-ack {}", event_id);
                return true;
            }
            break;
        }
    }
    return false;
}

std::vector<AlarmEvent> AlarmEngine::getActiveAlarms() const
{
    std::vector<AlarmEvent> result;
    for (const auto& ev : m_events) {
        if (ev.isActive()) {
            result.push_back(ev);
        }
    }
    return result;
}

std::vector<AlarmEvent> AlarmEngine::getAllEvents() const
{
    return m_events;
}

int AlarmEngine::activeAlarmCount() const
{
    int count = 0;
    for (const auto& ev : m_events) {
        if (ev.isActive()) ++count;
    }
    return count;
}
```

```cpp
QVariant AlarmTableModel::data(const QModelIndex& index, int role) const
{
    if (!index.isValid() ||
        index.row() >= static_cast<int>(m_events.size())) {
        return QVariant();
    }

    const AlarmEvent& ev = m_events[index.row()];

    switch (role) {
    case Qt::DisplayRole: {
        switch (index.column()) {
        case 0:
            return QDateTime::fromMSecsSinceEpoch(
                static_cast<qint64>(ev.trigger_time_ms))
                .toString("HH:mm:ss");
        case 1: return QString::fromStdString(ev.message);
        case 2: return QString::fromStdString(ev.tag_name);
        case 3: return QString::number(ev.trigger_value, 'f', 1);
        case 4: return priorityText(ev.priority);
        case 5: return stateText(ev.state);
        }
        break;
    }

    case Qt::ForegroundRole:
        // 🎯 优先级列按颜色显示，状态列"未确认"用红色高亮
        if (index.column() == 4) {
            return priorityColor(ev.priority);
        }
        if (index.column() == 5) {
            if (ev.state == AlarmState::ACTIVE)
                return QColor("#E74C3C");   // 未确认 = 红
            if (ev.state == AlarmState::CLEARED_UNACK)
                return QColor("#F39C12");   // 恢复待确认 = 黄
            return QColor("#2ECC71");        // 已确认/已关闭 = 绿
        }
        return QColor("#ECF0F1");

    case Qt::TextAlignmentRole:
        if (index.column() == 3)
            return static_cast<int>(Qt::AlignRight | Qt::AlignVCenter);
        return static_cast<int>(Qt::AlignLeft | Qt::AlignVCenter);
    }

    return QVariant();
}
```

```cpp
void AlarmListWidget::refreshAlarms()
{

    int count = engine.activeAlarmCount();

void AlarmListWidget::onAcknowledge()

        return;

    if (AlarmEngine::instance().acknowledge(event_id.toStdString())) {
        refreshAlarms();
    }

        return;
    }

    QString event_id = m_model->eventIdAt(index.row());
    if (AlarmEngine::instance().acknowledgeClear(event_id.toStdString())) {
        refreshAlarms();
    }
```

### 3.0 预备知识：配方与仿真的关系

第二阶段写的 SimEngine 用的是**硬编码参数**：目标温度 150°C、反应 60 秒。真实生产里，这些参数应该来自配方，由工程师在界面配置。

本阶段要做的是：把配方从"配置"变成"数据"——工程师可以新建、修改、保存配方，选定配方后下发给仿真引擎执行。

**配方和工艺阶段的关系：**

配方里的每个阶段，对应 SimReactorModel 的一个 ProcessStage：

```cpp
配方阶段          →  ProcessStage
"进料"           →  FEEDING
"加热"           →  HEATING
"恒温反应"        →  REACTING
"冷却"           →  COOLING
"出料"           →  DISCHARGING
```

每个阶段带一组参数（目标温度、目标液位、持续时间），执行引擎按参数控制仿真。

```cpp
// Recipe.h — 配方数据结构
//
// 配方 = 生产一个产品所需的完整工艺参数。
// 用 JSON 持久化（可读、可版本管理）。
//
// 数据结构的字段用 std::optional 表示"可选参数"：
//   有的阶段关心温度，有的关心液位，
//   用 optional 区分"没设置"和"设置为 0"。
// ============================================================
#pragma once

#include <string>
#include <vector>
#include <optional>
#include <cstdint>

/// @brief 配方中的一个工艺阶段

{

};

/// @brief 完整配方
struct Recipe
{
    std::string recipe_id;             // 配方编号，如 "RCP-001"
    std::string product_name;          // 产品名称
    std::string version = "v1.0";      // 版本号
    std::string author;                // 创建/修改人
    uint64_t create_time_ms = 0;       // 创建时间
    uint64_t modify_time_ms = 0;       // 最后修改时间
    std::vector<RecipeStage> stages;   // 工艺阶段列表
    std::string description;           // 备注说明
};
```

```cpp
// RecipeManager.cpp — 配方管理器实现
// ============================================================
#include "RecipeManager.h"
#include "common/Logger.h"
#include <nlohmann/json.hpp>
#include <QDir>
#include <QFile>
#include <QFileInfo>
#include <QDateTime>

using Json = nlohmann::json;

RecipeManager& RecipeManager::instance()

RecipeManager::RecipeManager()

void RecipeManager::initialize(const QString& recipe_dir)
{
    m_recipe_dir = recipe_dir;

    // 确保目录存在
    QDir dir(recipe_dir);
    if (!dir.exists()) dir.mkpath(".");

    loadAllRecipes();
    LOG_INFO("RecipeManager: initialized, {} recipes loaded",

void RecipeManager::loadAllRecipes()
{
    m_recipes.clear();

    QDir dir(m_recipe_dir);
    // 遍历目录下所有 .json 文件
    QStringList files = dir.entryList(QStringList() << "*.json", QDir::Files);

    for (const QString& file : files) {
        QFile f(dir.filePath(file));
        if (!f.open(QIODevice::ReadOnly)) continue;

        Recipe recipe = recipeFromJson(f.readAll().toStdString());
        f.close();

        if (!recipe.recipe_id.empty()) {
            m_recipes.push_back(recipe);
        }
    }
}

std::vector<Recipe> RecipeManager::getAllRecipes() const
{
    return m_recipes;
}

bool RecipeManager::findRecipe(const std::string& recipe_id, Recipe& out) const
{
    for (const auto& r : m_recipes) {
        if (r.recipe_id == recipe_id) {
            out = r;
            return true;
        }
    }
    return false;
}

bool RecipeManager::addRecipe(const Recipe& recipe)
{
    // 检查 ID 重复
    for (const auto& r : m_recipes) {
        if (r.recipe_id == recipe.recipe_id) {
            LOG_WARN("RecipeManager: recipe '{}' already exists",
                     recipe.recipe_id);
            return false;
        }
    }

    m_recipes.push_back(recipe);
    saveAll();
    emit recipesChanged();
    LOG_INFO("RecipeManager: added recipe '{}'", recipe.recipe_id);
    return true;
}

bool RecipeManager::updateRecipe(const Recipe& recipe)
{
    for (auto& r : m_recipes) {
        if (r.recipe_id == recipe.recipe_id) {
            r = recipe;
            saveAll();
            emit recipesChanged();
            return true;
        }
    }
    return false;
}

bool RecipeManager::deleteRecipe(const std::string& recipe_id)
{
    for (auto it = m_recipes.begin(); it != m_recipes.end(); ++it) {
        if (it->recipe_id == recipe_id) {
            m_recipes.erase(it);
            saveAll();
            emit recipesChanged();
            LOG_INFO("RecipeManager: deleted recipe '{}'", recipe_id);
            return true;
        }
    }
    return false;
}

void RecipeManager::saveAll()
{
    // 每个配方保存为一个独立的 JSON 文件
    for (const auto& recipe : m_recipes) {
        QString file_path = m_recipe_dir + "/"
                          + QString::fromStdString(recipe.recipe_id) + ".json";

        QFile f(file_path);
        if (!f.open(QIODevice::WriteOnly)) {
            LOG_ERROR("RecipeManager: cannot write {}", file_path.toStdString());
            continue;
        }

        f.write(recipeToJson(recipe).c_str());
        f.close();
    }
}

Recipe RecipeManager::recipeFromJson(const std::string& json_str) const
{
    Recipe recipe;
    try {
        Json j = Json::parse(json_str);

        recipe.recipe_id    = j.value("recipe_id", "");
        recipe.product_name = j.value("product_name", "");
        recipe.version      = j.value("version", "v1.0");
        recipe.author       = j.value("author", "");
        recipe.create_time_ms = j.value("create_time", 0);
        recipe.modify_time_ms = j.value("modify_time", 0);
        recipe.description  = j.value("description", "");

        if (j.contains("stages") && j["stages"].is_array()) {
            for (const auto& s : j["stages"]) {
                RecipeStage stage;
                stage.stage_name = s.value("stage_name", "");

                // std::optional 的处理：
                // JSON 里有这个字段才赋值，否则保持 nullopt
                if (s.contains("level_target"))
                    stage.level_target = s["level_target"].get<double>();
                if (s.contains("temp_target"))
                    stage.temp_target = s["temp_target"].get<double>();
                if (s.contains("temp_rate"))
                    stage.temp_rate = s["temp_rate"].get<double>();
                if (s.contains("agitator_speed"))
                    stage.agitator_speed = s["agitator_speed"].get<double>();
                if (s.contains("valve_open"))
                    stage.valve_open = s["valve_open"].get<double>();

                stage.duration_sec = s.value("duration_sec", 0);
                recipe.stages.push_back(stage);
            }
        }
    } catch (const std::exception& e) {
        LOG_ERROR("RecipeManager: parse failed - {}", e.what());
    }
    return recipe;
}

std::string RecipeManager::recipeToJson(const Recipe& recipe) const
{
    Json j;
    j["recipe_id"]    = recipe.recipe_id;
    j["product_name"] = recipe.product_name;
    j["version"]      = recipe.version;
    j["author"]       = recipe.author;
    j["create_time"]  = recipe.create_time_ms;
    j["modify_time"]  = recipe.modify_time_ms;
    j["description"]  = recipe.description;

    j["stages"] = Json::array();
    for (const auto& stage : recipe.stages) {
        Json s;
        s["stage_name"] = stage.stage_name;
        // std::optional 序列化：有值才写
        if (stage.level_target)    s["level_target"] = *stage.level_target;
        if (stage.temp_target)     s["temp_target"] = *stage.temp_target;
        if (stage.temp_rate)       s["temp_rate"] = *stage.temp_rate;
        if (stage.agitator_speed)  s["agitator_speed"] = *stage.agitator_speed;
        if (stage.valve_open)      s["valve_open"] = *stage.valve_open;
        s["duration_sec"] = stage.duration_sec;
        j["stages"].push_back(s);
    }

    return j.dump(4);   // 4 空格缩进，方便阅读
}
```

## 第四章：写配方执行引擎（RecipeExecutor）

### 4.0 预备知识：执行引擎做什么

RecipeManager 只是"管理配方数据"，RecipeExecutor 才是"让配方跑起来"。

执行引擎的工作：

1. 接收一个配方（从 RecipeManager 取出）
2. 从第一阶段开始，逐步执行每个工艺阶段
3. 每个阶段开始时，把设定值"下发"给 SimEngine（或真实 PLC）
4. 判断阶段完成条件（达到目标值 或 时间到）
5. 切换下一个阶段，直到所有阶段完成

**阶段切换条件：**

```
进料阶段   → 液位达到 level_target → 切换到加热
加热阶段   → 温度达到 temp_target → 切换到恒温
恒温阶段   → 时间达到 duration_sec → 切换到冷却
冷却阶段   → 温度降到 temp_target → 切换到出料
出料阶段   → 液位降到 level_target → 全部完成
```

### 4.1 写 RecipeExecutor.h

```cpp
// RecipeExecutor.h — 配方执行引擎
//
// 把配方"翻译"成对仿真引擎（或 PLC）的连续操作指令。

    Recipe m_recipe;                  // 当前配方
```

### 4.2 写 RecipeExecutor.cpp

**文件路径：** `D:\QtProject\UCS\src\business\recipe\RecipeExecutor.cpp`

```cpp
// ============================================================
// RecipeExecutor.cpp — 配方执行引擎实现
// ============================================================
#include "RecipeExecutor.h"
#include "simulation/SimEngine.h"
#include "simulation/SimReactorModel.h"
#include "core/rtdb/RealTimeDB.h"
#include "common/Logger.h"

RecipeExecutor::RecipeExecutor(QObject* parent)
    : QObject(parent)
{
    m_timer = new QTimer(this);
    connect(m_timer, &QTimer::timeout, this, &RecipeExecutor::onTick);
}

RecipeExecutor::~RecipeExecutor()
{
    stop();
}

void RecipeExecutor::bindEngine(SimEngine* engine)
{
    m_engine = engine;
}

bool RecipeExecutor::loadRecipe(const Recipe& recipe)
{
    if (recipe.stages.empty()) {
        LOG_ERROR("RecipeExecutor: recipe has no stages");
        return false;
    }
    m_recipe = recipe;
    m_current_stage = -1;
    LOG_INFO("RecipeExecutor: loaded recipe '{}' ({} stages)",
             recipe.recipe_id, recipe.stages.size());
    return true;
}

void RecipeExecutor::start()
{
    if (m_running || m_recipe.stages.empty()) return;

    m_running = true;
    switchToStage(0);   // 从第一阶段开始

    m_timer->start(200);   // 每 200ms 检查一次阶段状态
    LOG_INFO("RecipeExecutor: started recipe '{}'", m_recipe.recipe_id);
}

void RecipeExecutor::stop()
{
    if (!m_running) return;
    m_timer->stop();
    m_running = false;
    LOG_INFO("RecipeExecutor: stopped");
}

bool RecipeExecutor::isRunning() const
{
    return m_running;
}

int RecipeExecutor::currentStageIndex() const
{
    return m_current_stage;
}

QString RecipeExecutor::currentStageName() const
{
    if (m_current_stage < 0 ||
        m_current_stage >= static_cast<int>(m_recipe.stages.size())) {
        return "未执行";
    }
    return QString::fromStdString(
        m_recipe.stages[m_current_stage].stage_name);
}

int RecipeExecutor::totalStages() const
{
    return static_cast<int>(m_recipe.stages.size());
}

void RecipeExecutor::switchToStage(int index)
{
    if (index >= static_cast<int>(m_recipe.stages.size())) {
        return;
    }

    m_current_stage = index;
    const RecipeStage& stage = m_recipe.stages[index];

    // 🎯 把配方参数"下发"到仿真引擎
    if (m_engine) {
        auto& model = m_engine->model();
        auto& params = const_cast<ReactorParams&>(model.params());

        // 更新目标参数
        if (stage.temp_target)    params.setpoint_temp = *stage.temp_target;
        if (stage.level_target)   params.setpoint_level = *stage.level_target;

        // 设置阀门（根据阶段特征）
        if (stage.valve_open) {
            // 根据阶段名判断开哪个阀
            const std::string& name = stage.stage_name;
            if (name == "进料") {
                model.setValve("HV-101", *stage.valve_open);
            } else if (name == "加热") {
                model.setValve("TV-101", *stage.valve_open);
            } else if (name == "冷却") {
                model.setValve("TV-102", *stage.valve_open);
            } else if (name == "出料") {
                model.setValve("HV-103", *stage.valve_open);
            }
        }

        // 设置工艺阶段
        const std::string& name = stage.stage_name;
        if (name == "进料")      model.setStage(ProcessStage::FEEDING);
        else if (name == "加热") model.setStage(ProcessStage::HEATING);
        else if (name == "恒温反应" || name == "恒温")
                                 model.setStage(ProcessStage::REACTING);
        else if (name == "冷却") model.setStage(ProcessStage::COOLING);
        else if (name == "出料") model.setStage(ProcessStage::DISCHARGING);
    }

    // 发出阶段切换信号
    emit stageChanged(index, currentStageName());

    LOG_INFO("RecipeExecutor: stage {} '{}' started",
             index, stage.stage_name);
}

void RecipeExecutor::onTick()
{
    if (!m_running || !m_engine) return;

    // 判断当前阶段是否完成
    if (isStageComplete()) {
        // 切换到下一阶段
        int next = m_current_stage + 1;
        if (next >= static_cast<int>(m_recipe.stages.size())) {
            // 所有阶段完成
            m_running = false;
            m_timer->stop();
            m_current_stage = -1;
            emit progressUpdated(100);
            emit recipeFinished();
            LOG_INFO("RecipeExecutor: recipe '{}' finished",
                     m_recipe.recipe_id);
            return;
        }
        switchToStage(next);
    }

    // 更新进度
    int percent = static_cast<int>(
        (m_current_stage + 1.0) / m_recipe.stages.size() * 100);
    emit progressUpdated(percent);
}

bool RecipeExecutor::isStageComplete() const
{
    if (!m_engine || m_current_stage < 0 ||
        m_current_stage >= static_cast<int>(m_recipe.stages.size())) {
        return false;
    }

    const RecipeStage& stage = m_recipe.stages[m_current_stage];
    const auto& state = m_engine->model().getState();

    // 🎯 时间型阶段：持续时间到了就算完成
    if (stage.duration_sec > 0) {
        return m_engine->model().stageElapsedTime() >= stage.duration_sec;
    }

    // 目标型阶段：达到目标值才算完成
    const std::string& name = stage.stage_name;
    if (name == "进料") {
        return stage.level_target &&
               state.level >= *stage.level_target * 0.98;
    }
    if (name == "加热") {
        return stage.temp_target &&
               state.temperature >= *stage.temp_target * 0.97;
    }
    if (name == "冷却") {
        return stage.temp_target &&
               state.temperature <= *stage.temp_target;
    }
    if (name == "出料") {
        return stage.level_target &&
               state.level <= *stage.level_target;
    }

    return false;
}
```

## 第五章：写报表系统（ReportGenerator）

### 5.0 预备知识：HTML 报表生成原理

报表 = 把生产数据组织成易读的表格。我们用 HTML 描述版式，因为：

- HTML 表格排版和写网页一样直观
- Qt 的 `QTextDocument` 能直接加载 HTML
- `QPrinter` 能把 QTextDocument 输出成 PDF 或打印

核心流程：

```
数据（RealTimeDB / HistoryDB）
    │ 拼 HTML 字符串
    ▼
"<table><tr><td>温度</td><td>150.3</td>...</table>"
    │ QTextDocument::setHtml()
    ▼
QTextDocument（排版后的文档）
```

```cpp
QString ReportGenerator::buildHeader(const QDate& date)

QString ReportGenerator::buildProductionTable()
{
    // 从 RealTimeDB 取当前所有测点值
    auto values = RealTimeDB::instance().getAllLatestValues();

    QString html = "<h2>一、生产数据汇总</h2>";
    html += "<table border='1' cellspacing='0' cellpadding='5'>";
    html += "<tr style='background:#e0e0e0;'>"
            "<th>位号</th><th>描述</th><th>数值</th><th>单位</th>"
            "<th>质量</th><th>时间</th></tr>";

    for (const auto& pt : values) {
        QString quality = (pt.quality >= Quality::UNCERTAIN) ? "正常" : "故障";
        QDateTime ts = QDateTime::fromMSecsSinceEpoch(
            static_cast<qint64>(pt.timestamp_ms));

        html += QString(
            "<tr>"
            "<td>%1</td><td>%2</td><td>%3</td><td>%4</td>"
            "<td>%5</td><td>%6</td>"
            "</tr>")
            .arg(QString::fromStdString(pt.tag_name))
            .arg(QString::fromStdString(pt.description))
            .arg(pt.scaled_value, 0, 'f', 1)
            .arg(QString::fromStdString(pt.unit))
            .arg(quality)
            .arg(ts.toString("HH:mm:ss"));
    }

    html += "</table>";
    return html;
}

QString ReportGenerator::buildAlarmTable()
{
    auto events = AlarmEngine::instance().getAllEvents();

    QString html = "<h2>二、报警记录</h2>";
    if (events.empty()) {
        html += "<p>当日无报警记录。</p>";
        return html;
    }

    html += "<table border='1' cellspacing='0' cellpadding='5'>";
    html += "<tr style='background:#e0e0e0;'>"
            "<th>时间</th><th>报警描述</th><th>位号</th>"
            "<th>触发值</th><th>状态</th></tr>";

    for (const auto& ev : events) {
        QDateTime ts = QDateTime::fromMSecsSinceEpoch(
            static_cast<qint64>(ev.trigger_time_ms));

        QString state;
        switch (ev.state) {
        case AlarmState::ACTIVE:        state = "未确认"; break;
        case AlarmState::ACKNOWLEDGED:  state = "已确认"; break;
        case AlarmState::CLEARED_UNACK: state = "恢复待确认"; break;
        case AlarmState::INACTIVE:      state = "已关闭"; break;
        }

        html += QString(
            "<tr><td>%1</td><td>%2</td><td>%3</td>"
            "<td>%4</td><td>%5</td></tr>")
            .arg(ts.toString("HH:mm:ss"))
            .arg(QString::fromStdString(ev.message))
            .arg(QString::fromStdString(ev.tag_name))
            .arg(ev.trigger_value, 0, 'f', 1)
            .arg(state);
    }

    html += "</table>";
    return html;
}

QString ReportGenerator::buildFooter()
{
    return "<hr><p style='text-align:center;font-size:12px;'>"
           "本报表由 UCS 上位机系统自动生成</p>";
}

bool ReportGenerator::exportToPdf(const QString& html,
                                   const QString& file_path)
{
    // 🎯 QTextDocument 加载 HTML 并排版
    QTextDocument doc;
    doc.setHtml(html);

    // 🎯 QPrinter 输出到 PDF
    QPrinter printer(QPrinter::HighResolution);
    printer.setOutputFormat(QPrinter::PdfFormat);
    printer.setOutputFileName(file_path);

    // 把文档"打印"到 PDF
    doc.print(&printer);

    LOG_INFO("ReportGenerator: exported PDF to {}",
             file_path.toStdString());
    return true;
}

bool ReportGenerator::saveToHtml(const QString& html,
                                  const QString& file_path)
{
    QFile file(file_path);
    if (!file.open(QIODevice::WriteOnly | QIODevice::Text)) {
        return false;
    }
    file.write(html.toUtf8());
    file.close();
    return true;
}
```

```cpp
// ============================================================
// LogViewWidget.cpp — 日志查看界面实现
// ============================================================
#include "LogViewWidget.h"
#include <QVBoxLayout>
#include <QHBoxLayout>
#include <QListWidget>
#include <QComboBox>
#include <QPushButton>
#include <QLabel>
#include <QFile>

LogViewWidget::LogViewWidget(QWidget* parent)
    : QWidget(parent)
{
    setupUI();

    m_refresh_timer = new QTimer(this);
    connect(m_refresh_timer, &QTimer::timeout,
            this, &LogViewWidget::reloadLogs);
    m_refresh_timer->start(3000);   // 每 3 秒自动刷新
}

void LogViewWidget::setupUI()
{
    auto* layout = new QVBoxLayout(this);
    layout->setContentsMargins(10, 10, 10, 10);
    layout->setSpacing(8);

    // ---- 工具栏 ----
    auto* toolbar = new QHBoxLayout();
    toolbar->addWidget(new QLabel("级别过滤:"));

    m_level_filter = new QComboBox();
    m_level_filter->addItem("全部");
    m_level_filter->addItem("INFO");
    m_level_filter->addItem("WARNING");
    m_level_filter->addItem("ERROR");
    connect(m_level_filter, &QComboBox::currentTextChanged,
            this, &LogViewWidget::reloadLogs);
    toolbar->addWidget(m_level_filter);

    m_reload_btn = new QPushButton("刷新");
    connect(m_reload_btn, &QPushButton::clicked,
            this, &LogViewWidget::reloadLogs);
    toolbar->addWidget(m_reload_btn);

    m_clear_btn = new QPushButton("清空");
    connect(m_clear_btn, &QPushButton::clicked,
            this, &LogViewWidget::clearLogs);
    toolbar->addWidget(m_clear_btn);

    toolbar->addStretch();
    layout->addLayout(toolbar);

    // ---- 日志列表 ----
    m_log_list = new QListWidget();
    m_log_list->setFont(QFont("Consolas", 9));   // 等宽字体，对齐好看
    layout->addWidget(m_log_list, 1);
}

void LogViewWidget::reloadLogs()
{
    m_log_list->clear();

    QFile file(m_log_path);
    if (!file.open(QIODevice::ReadOnly | QIODevice::Text)) {
        m_log_list->addItem("[无法打开日志文件: " + m_log_path + "]");
        return;
    }

    QString filter = m_level_filter->currentText();

    // 读取所有行（日志文件不会太大，直接全读）
    // 只取最后 500 行，避免界面卡顿
    QStringList all_lines;
    while (!file.atEnd()) {
        all_lines << QString::fromUtf8(file.readLine());
    }
    file.close();

    // 倒序取最后 500 行
    int start = qMax(0, all_lines.size() - 500);
    for (int i = start; i < all_lines.size(); ++i) {
        QString line = all_lines[i].trimmed();
        if (line.isEmpty()) continue;

        // 级别过滤
        if (filter != "全部" && !line.contains(filter)) {
            continue;
        }

        auto* item = new QListWidgetItem(line);

        // 🎯 按级别着色
        if (line.contains("error", Qt::CaseInsensitive) ||
            line.contains("critical", Qt::CaseInsensitive)) {
            item->setForeground(QColor("#E74C3C"));   // 红
        } else if (line.contains("warn", Qt::CaseInsensitive)) {
            item->setForeground(QColor("#F39C12"));   // 黄
        } else if (line.contains("debug", Qt::CaseInsensitive)) {
            item->setForeground(QColor("#7F8C8D"));   // 灰
        } else {
            item->setForeground(QColor("#2ECC71"));   // 绿（info）
        }

        m_log_list->addItem(item);
    }

    // 滚动到底部（最新日志）
    m_log_list->scrollToBottom();
}

void LogViewWidget::clearLogs()
{
    m_log_list->clear();
}
```
