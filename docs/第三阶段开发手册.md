### 1. 什么是 QPainter？为什么要自绘控件？

Qt 自带的控件（QPushButton、QLabel、QProgressBar）都是"通用型"的——长得方方正正，外观靠 QSS 调整。但工业上位机需要这些：

```
      ╭──────╮
     ╱  表盘  ╲      ← 圆形仪表盘（温度表、压力表）
    │  指针    │
    │   刻度   │
     ╲        ╱
      ╰──────╯

    ● 运行      ← LED 状态灯（圆点，绿色=运行，红色=停止）

    ████████████  ← 液位柱（垂直填充，模拟釜内液位）
    ░░░░░░░░░░░░
```

这些控件 Qt 没有现成的，必须自己画。Qt 提供了 **QPainter**——它是一个"画笔"，你可以用它在任何 QWidget 上画线、圆、矩形、文字、图片。

**QPainter 的工作方式：**

```cpp
void GaugeWidget::paintEvent(QPaintEvent* event)
{
    // Qt 会在"需要重绘"时自动调用这个函数
    // （比如窗口首次显示、被遮挡后露出、你调用 update()）

    QPainter painter(this);       // 1. 创建画笔，绑定到当前控件
    painter.setRenderHint(QPainter::Antialiasing);  // 2. 抗锯齿（线条平滑）

    painter.setPen(QPen(Qt::white, 2));   // 3. 设置"描边"画笔（白色，2px 粗）
    painter.drawEllipse(10, 10, 100, 100);          // 4. 画圆

    painter.setBrush(Qt::red);            // 5. 设置"填充"画刷（红色）
    painter.drawEllipse(40, 40, 40, 40);            // 6. 画实心圆
}
```

关键规则：

- 绘画代码**只能写在 paintEvent() 里**（或它调用的函数里）
- 想重新画？调用 `update()` 或 `repaint()`，Qt 会在合适的时候调用 paintEvent
- QPainter 的坐标系：原点在控件左上角，x 向右，y 向下

**update() vs repaint() 的区别：**

- `update()`：标记"需要重绘"，Qt 会在下一个事件循环时合并多次 update 后重绘一次（推荐）
- `repaint()`：立即重绘（可能导致频繁重绘，一般不用）

### 2. 什么是 Model/View 架构？

假设要显示 200 个测点的实时数据表格。传统做法：

```cpp
// 笨办法：手动维护 200 行表格数据
table->setItem(0, 0, new QTableWidgetItem("TE-101"));
table->setItem(0, 1, new QTableWidgetItem("150.3"));
// ... 数据变了再一行一行更新
```

问题：数据和显示混在一起了，更新逻辑散乱，排序筛选很难做。

**Model/View 架构**把"数据"和"显示"分离：

```
┌──────────────┐      ┌──────────────┐
│    Model     │      │     View     │
│ （数据层）     │      │ （显示层）     │
│ QAbstract-   │──────→│  QTableView  │
│ TableModel   │ 询问  │  只负责画出来 │
│              │ 数据  │              │
│ 维护数据数组  │←──────│ 需要哪行哪列？│
└──────────────┘      └──────────────┘
```

View 每次要画一行时，问 Model："第 3 行第 1 列是什么？"Model 返回数据。数据变化时 Model 发出 `dataChanged` 信号，View 自动重绘相关区域。

好处：

- 数据更新逻辑集中在 Model 里，一处修改
- 同一个 Model 可以同时被表格、图表等多个 View 使用
- 天然支持排序、筛选（加一个 ProxyModel 层）

### 3. 什么是 QGraphicsView 框架？

工艺流程图（P&ID）需要画这些东西：反应釜、管道、阀门、泵，还要支持：

- 鼠标缩放、平移
- 点击某个设备弹出详情
- 管道流体动画
- 液位实时填充

如果全部用 QPainter 手写，你需要自己处理"鼠标点的是哪个设备""怎么平移""怎么碰撞检测"——工作量巨大。

**QGraphicsView 框架**是 Qt 提供的"2D 场景系统"，它把这些都做好了。它由三部分组成：

```
QGraphicsScene（场景）
    │ 管理所有图元，是一块"虚拟画布"
    │ 可以很大（比如 3000x2000），超出屏幕也没关系
    │
    ├── QGraphicsItem（图元）——场景里的"东西"
    │     ├── ReactorItem（反应釜）
    │     ├── PipeItem（管道）
    │     ├── ValveItem（阀门）
    │     └── PumpItem（泵）
    │     每个图元知道自己的位置、形状、怎么画自己
    │
QGraphicsView（视图）
    │ 是一块"观察窗口"，决定用户看到场景的哪一部分
    │ 内置缩放（scale）、平移（drag）、坐标转换
```

关键概念：

- **场景坐标**：图元在场景里的位置（世界坐标）
- **视图坐标**：用户屏幕上看到的坐标
- 框架自动完成两者转换，缩放平移时图元不需要改代码

### 4. 什么是 QtCharts？

趋势曲线是上位机的标配。QtCharts 是 Qt 官方的图表模块，主要类：

```
QChart             ← 一张图（容器，管标题、图例、坐标轴）
 ├── QLineSeries   ← 一条折线（数据点集合）
 ├── QDateTimeAxis ← X 轴（时间轴）
 ├── QValueAxis    ← Y 轴（数值轴）
 └── QChartView    ← 把 QChart 显示出来的控件
```

使用模式：

```cpp
auto* series = new QLineSeries();      // 创建一条线
series->append(x1, y1);                // 往线上加点
series->append(x2, y2);

auto* chart = new QChart();            // 创建图
chart->addSeries(series);              // 线放进图里
chart->createDefaultAxes();            // 自动创建坐标轴

auto* view = new QChartView(chart);    // 显示图的控件
view->setRenderHint(QPainter::Antialiasing);  // 平滑曲线
```

**一个坑要提醒：** 数据点不能无限加。1 万个点还能流畅显示，100 万个点就会卡。所以要配合 RingBuffer 控制点数（最多 600 个），或者用降采样。

### 5. 什么是 SQLite？为什么上位机用它存历史数据？

历史数据（比如"过去 30 天每分钟的温度"）需要持久化存储。选择：

| 方案              | 特点                | 适合场景    |
| --------------- | ----------------- | ------- |
| 文本文件 (CSV)      | 简单但查询慢            | 数据导出    |
| SQLite          | 零配置、单文件、支持 SQL 查询 | 单机上位机   |
| MySQL/SQLServer | 需装服务器、支持多客户端      | 多工作站工厂  |
| InfluxDB        | 时序数据库，专为传感器数据优化   | 大数据量云平台 |

SQLite 是最适合单机版上位机的：

- **零配置**：不需要安装数据库服务，就是一个 .db 文件
- **SQL 支持**：可以用 `SELECT * FROM data WHERE timestamp > ...` 查询
- **Qt 内置驱动**：QtSql 模块直接支持，无需第三方库
- **够用**：单表几百万行数据查询依然很快（有索引的话）

## 第一章：自绘仪表盘控件

### 1.0 为什么先从自绘控件开始

第二阶段的 DashboardWidget 用 QLabel 显示数字——能用，但不像工业软件。真实的 SCADA 系统仪表盘是这样的：圆形表盘带指针、LED 灯闪烁、液位柱上下浮动。

本章的三个控件都是自绘的，它们将成为后续所有界面的"零件"。学会这一章，你就掌握了 Qt 自绘控件的完整套路：

```
套路三步走：
1. 继承 QWidget，重写 paintEvent()
2. 提供 setValue()/setState() 方法，内部存值后调用 update()
```


### 1.2 写 GaugeWidget（圆形仪表盘）

**文件路径：** `D:\QtProject\UCS\src\ui\GaugeWidget.h`

圆形仪表盘的构造（先想清楚再写代码）：

```
        90°
         │
  135°   │   45°
    ╲    │    ╱
      ╲  │  ╱
180° ────●──── 0°        ● = 圆心
      ╱  │  ╲
    ╱    │    ╲
  -135°  │   -45°
        -90°

我们要画的元素（从外到内）：
1. 外圈圆弧（量程背景）      —— drawArc
2. 刻度线（每 10% 一条）     —— drawLine
3. 报警区间弧（红色区域）    —— drawArc（粗笔）
4. 指针                     —— drawLine（从圆心出发，角度由当前值决定）
5. 中心圆点                 —— drawEllipse
6. 数值文字                 —— drawText
7. 单位 + 位号文字           —— drawText
```

角度换算：Qt 的 drawArc 使用的角度单位是"1/16 度"，而且 0° 在 3 点钟方向，逆时针为正。我们的仪表从 -225° 画到 45°（即 270° 的量程范围）。

```cpp
// ============================================================
// GaugeWidget.h — 圆形仪表盘控件
//
// 自绘控件的标准做法：
//   1. 继承 QWidget
//   2. 重写 paintEvent() 绘制外观
//   3. 提供 setValue() 等接口，值变化时调用 update() 触发重绘
//
// 建议控件最小尺寸 150x150，太小时文字会重叠
// ============================================================
#pragma once

#include <QWidget>

class GaugeWidget : public QWidget
{
    Q_OBJECT

public:
    explicit GaugeWidget(QWidget* parent = nullptr);

    // ---- 配置接口 ----

    /// @brief 设置量程范围
    /// @param min_value 最小值（如 0.0）
    /// @param max_value 最大值（如 300.0）
    void setRange(double min_value, double max_value);

    /// @brief 设置显示标题（位号 + 描述）
    /// @param title 如 "TE-101"
    /// @param subtitle 如 "釜内温度"
    void setTitle(const QString& title, const QString& subtitle);

    /// @brief 设置单位
    void setUnit(const QString& unit);

    /// @brief 设置报警限值（超过画红区）
    /// @param high_limit 高限值，如 200.0；设为 NaN 表示不启用
    void setHighLimit(double high_limit);

    // ---- 数据接口 ----

    /// @brief 设置当前值（会触发重绘）
    void setValue(double value);

    /// @brief 设置数据是否有效（无效时灰色显示 "---"）
    void setValid(bool valid);

    /// @brief 获取当前值
    double value() const;

    // Qt 建议控件尺寸（QSizePolicy 会参考它）
    QSize sizeHint() const override;
    QSize minimumSizeHint() const override;

protected:
    /// @brief Qt 绘画事件——所有绘制都在这里
    void paintEvent(QPaintEvent* event) override;

private:
    // ---- 绘制辅助函数（把 paintEvent 拆小，方便阅读）----
    void drawBackground(QPainter& painter);   // 画外圈背景弧
    void drawTicks(QPainter& painter);        // 画刻度线和刻度数字
    void drawAlarmZone(QPainter& painter);    // 画报警红区
    void drawNeedle(QPainter& painter);       // 画指针
    void drawText(QPainter& painter);         // 画数值和标题

    /// @brief 把"值"换算成"角度"
    /// 值在量程中的比例 → 指针应处的角度
    double valueToAngle(double value) const;

    // ---- 配置数据 ----
    double m_min = 0.0;          // 量程下限
    double m_max = 100.0;        // 量程上限
    double m_high_limit = 0.0;   // 高限报警值
    bool m_has_limit = false;    // 是否启用高限

    QString m_title;             // 位号
    QString m_subtitle;          // 描述
    QString m_unit;              // 单位

    // ---- 运行数据 ----
    double m_value = 0.0;        // 当前值
    bool m_valid = true;         // 数据是否有效

    // 仪表的角度范围：从 -225° 到 45°（共 270°）
    // Qt 坐标：0° 在 3 点钟方向，逆时针为正
    static constexpr int START_ANGLE = -225;
    static constexpr int SPAN_ANGLE = 270;
};
```

**文件路径：** `D:\QtProject\UCS\src\ui\GaugeWidget.cpp`

这是整个第三阶段最"数学"的一段代码，我逐行解释。

```cpp
// ============================================================
// GaugeWidget.cpp — 圆形仪表盘实现
// ============================================================
#include "GaugeWidget.h"
#include <QPainter>
#include <QPaintEvent>
#include <QtMath>      // qSin, qCos, qDegreesToRadians
#include <cmath>       // std::isnan

GaugeWidget::GaugeWidget(QWidget* parent)
    : QWidget(parent)
{
    // 控件默认背景透明，显示由 paintEvent 全权负责
    setAttribute(Qt::WA_TranslucentBackground);
}

void GaugeWidget::setRange(double min_value, double max_value)
{
    m_min = min_value;
    m_max = max_value;
    update();  // 量程变了，刻度位置要重算 → 触发重绘
}

void GaugeWidget::setTitle(const QString& title, const QString& subtitle)
{
    m_title = title;
    m_subtitle = subtitle;
    update();
}

void GaugeWidget::setUnit(const QString& unit)
{
    m_unit = unit;
    update();
}

void GaugeWidget::setHighLimit(double high_limit)
{
    if (std::isnan(high_limit)) {
        m_has_limit = false;
    } else {
        m_high_limit = high_limit;
        m_has_limit = true;
    }
    update();
}

void GaugeWidget::setValue(double value)
{
    // 把值钳制在量程内，防止指针转到表外
    m_value = qBound(m_min, value, m_max);
    update();  // 值变了 → 触发重绘（这就是"数据驱动显示"）
}

void GaugeWidget::setValid(bool valid)
{
    m_valid = valid;
    update();
}

double GaugeWidget::value() const
{
    return m_value;
}

QSize GaugeWidget::sizeHint() const
{
    // 建议尺寸：200x200
    return QSize(200, 200);
}

QSize GaugeWidget::minimumSizeHint() const
{
    return QSize(120, 120);
}

double GaugeWidget::valueToAngle(double value) const
{
    // 线性映射：值 → 角度
    // value = m_min  → START_ANGLE (-225°)
    // value = m_max  → START_ANGLE + SPAN_ANGLE (45°)
    if (m_max <= m_min) return START_ANGLE;
    double ratio = (value - m_min) / (m_max - m_min);
    return START_ANGLE + ratio * SPAN_ANGLE;
}

void GaugeWidget::paintEvent(QPaintEvent* event)
{
    Q_UNUSED(event);  // 这个参数我们用不到，显式标记"故意不用"

    QPainter painter(this);

    // 🎯 抗锯齿：让圆和线条边缘平滑，不开会有明显锯齿
    painter.setRenderHint(QPainter::Antialiasing);

    // 🎯 坐标系变换（这是自绘控件最重要的技巧！）
    //
    // 问题：控件可能被拉伸成任意大小，我们的画图坐标会乱。
    // 解决：把坐标系"标准化"——无论控件多大，
    //       我们都以 (100, 100) 为圆心、100 为半径来画图，
    //       让 Qt 帮我们做缩放。
    //
    // 步骤：
    //   1. 把坐标原点平移到控件中心
    //   2. 计算缩放比例（控件最小边 / 200）
    //   3. 应用缩放
    //
    // 之后所有画图代码都用"标准化坐标"：
    // 圆心在 (0, 0)，表盘半径约 90

    painter.translate(width() / 2.0, height() / 2.0);

    double scale = qMin(width(), height()) / 200.0;
    painter.scale(scale, scale);

    // 按层次依次绘制（先画的在下面）
    drawBackground(painter);
    drawTicks(painter);
    drawAlarmZone(painter);
    drawNeedle(painter);
    drawText(painter);
}

void GaugeWidget::drawBackground(QPainter& painter)
{
    // 画表盘外圈圆弧（深灰色背景弧）
    //
    // drawArc 参数说明：
    //   QRectF(-90, -90, 180, 180)  —— 圆弧外接矩形（圆心0,0 半径90）
    //   startAngle * 16             —— 起始角（Qt 角度单位是 1/16 度！）
    //   spanAngle * 16              —— 跨度角
    //
    // ⚠️ 注意 Qt 的角度是 1/16 度，所以要乘 16
    QPen pen(QColor("#34495E"), 8);   // 深灰，8px 粗
    pen.setCapStyle(Qt::FlatCap);      // 平头端点
    painter.setPen(pen);
    painter.setBrush(Qt::NoBrush);     // 不填充，只要弧线

    painter.drawArc(QRectF(-90, -90, 180, 180),
                    START_ANGLE * 16, SPAN_ANGLE * 16);
}

void GaugeWidget::drawTicks(QPainter& painter)
{
    // 画刻度线和数字
    // 一共 11 个刻度（0%, 10%, 20% ... 100%）

    QPen pen(QColor("#7F8C8D"), 2);
    painter.setPen(pen);

    for (int i = 0; i <= 10; ++i) {
        // 当前刻度对应的值
        double value = m_min + (m_max - m_min) * i / 10.0;
        // 换算成角度
        double angle = valueToAngle(value);
        // 角度转弧度（三角函数用弧度）
        double rad = qDegreesToRadians(angle);

        // 🎯 刻度线是"从外向内"的短线
        // 外端点：半径 80 的圆周上
        // 内端点：半径 70 的圆周上（大刻度）或 75（小刻度）
        double outer_x = 80 * qCos(rad);
        double outer_y = 80 * qSin(rad);
        double inner_x = 70 * qCos(rad);
        double inner_y = 70 * qSin(rad);

        painter.drawLine(QPointF(inner_x, inner_y),
                         QPointF(outer_x, outer_y));

        // 画刻度数字（只画主刻度：每 20% 一个）
        if (i % 2 == 0) {
            double text_r = 55;  // 文字在半径 55 的位置
            double tx = text_r * qCos(rad);
            double ty = text_r * qSin(rad);

            // 数字格式化（整数显示，不显示小数）
            QString text = QString::number(static_cast<int>(value));

            painter.setPen(QColor("#BDC3C7"));
            QFont font = painter.font();
            font.setPointSize(7);
            painter.setFont(font);

            // drawText 的矩形以 (tx,ty) 为中心
            painter.drawText(QRectF(tx - 15, ty - 8, 30, 16),
                             Qt::AlignCenter, text);

            painter.setPen(QColor("#7F8C8D"), 2);  // 恢复刻度笔
        }
    }
}

void GaugeWidget::drawAlarmZone(QPainter& painter)
{
    if (!m_has_limit) return;

    // 高限报警区：从报警值到量程最大值画红色粗弧
    double start_angle = valueToAngle(m_high_limit);
    double end_angle = START_ANGLE + SPAN_ANGLE;  // 量程末尾角度
    double span = end_angle - start_angle;

    if (span <= 0) return;

    QPen pen(QColor("#E74C3C"), 6);   // 红色，6px
    pen.setCapStyle(Qt::FlatCap);
    painter.setPen(pen);
    painter.setBrush(Qt::NoBrush);

    painter.drawArc(QRectF(-90, -90, 180, 180),
                    static_cast<int>(start_angle * 16),
                    static_cast<int>(span * 16));
}

void GaugeWidget::drawNeedle(QPainter& painter)
{
    // 指针颜色：超过报警限变红，数据无效变灰
    QColor needle_color;
    if (!m_valid) {
        needle_color = QColor("#7F8C8D");  // 灰
    } else if (m_has_limit && m_value >= m_high_limit) {
        needle_color = QColor("#E74C3C");  // 红（报警）
    } else {
        needle_color = QColor("#4A90D9");  // 蓝（正常）
    }

    // 🎯 用 painter.save() / rotate() / restore() 画指针
    //
    // 技巧：不直接计算指针端点的三角函数坐标，
    // 而是"旋转坐标系"——把坐标系转到指针方向，
    // 然后画一条沿 x 轴的直线，画完再转回来。
    // 这样代码更直观，也不容易算错。

    painter.save();   // 保存当前坐标系状态

    double angle = valueToAngle(m_value);
    // Qt 的 rotate 是顺时针为正，我们的角度体系一致
    painter.rotate(angle);

    // 现在 x 轴正方向就是指针方向，直接画线
    QPen pen(needle_color, 3);
    pen.setCapStyle(Qt::RoundCap);   // 圆头指针
    painter.setPen(pen);
    painter.drawLine(QPointF(0, 0), QPointF(65, 0));  // 长 65

    painter.restore();  // 恢复坐标系

    // 画中心圆点（盖住指针根部）
    painter.setPen(Qt::NoPen);
    painter.setBrush(needle_color);
    painter.drawEllipse(QPointF(0, 0), 6, 6);
}

void GaugeWidget::drawText(QPainter& painter)
{
    painter.setPen(QColor("#ECF0F1"));

    // 数值（大号，表盘下方）
    QFont font = painter.font();
    font.setPointSize(12);
    font.setBold(true);
    painter.setFont(font);

    QString value_text = m_valid
        ? QString::number(m_value, 'f', 1) + " " + m_unit
        : "---";

    // 画在表盘下半部分（y=40 区域）
    painter.drawText(QRectF(-50, 40, 100, 20),
                     Qt::AlignCenter, value_text);

    // 位号（上方）
    font.setPointSize(9);
    font.setBold(false);
    painter.setFont(font);
    painter.setPen(QColor("#BDC3C7"));
    painter.drawText(QRectF(-50, -45, 100, 16),
                     Qt::AlignCenter, m_title);

    // 描述（最上方）
    if (!m_subtitle.isEmpty()) {
        font.setPointSize(7);
        painter.setFont(font);
        painter.setPen(QColor("#7F8C8D"));
        painter.drawText(QRectF(-50, -60, 100, 14),
                         Qt::AlignCenter, m_subtitle);
    }
}
```

```cpp
        m_blink_on = !m_blink_on;
        update();

    Q_UNUSED(event);

    QPainter painter(this);
    painter.setRenderHint(QPainter::Antialiasing);

    // 灯的直径取控件高度（保证是圆形）
    int diameter = qMin(height() - 4, 20);
    int cx = diameter / 2 + 2;         // 圆心 x
    int cy = height() / 2;             // 圆心 y（垂直居中）

    // 🎯 闪烁逻辑：报警且处于"灭"相位时，画暗色
    QColor color = stateColor();
    if (m_state == IndicatorState::ALARM && m_blinking && !m_blink_on) {
        color = color.darker(200);  // 变暗 2 倍

    // 画灯（实心圆 + 高光效果）
    // 用径向渐变模拟 LED 的立体感：中心亮、边缘暗
    QRadialGradient gradient(cx - diameter / 4, cy - diameter / 4, diameter);
    gradient.setColorAt(0.0, color.lighter(150));  // 中心偏亮
    gradient.setColorAt(1.0, color.darker(120));   // 边缘偏暗

    painter.setPen(QPen(color.darker(150), 1));   // 深色描边
    painter.setBrush(gradient);
    painter.drawEllipse(cx - diameter / 2, cy - diameter / 2,
                        diameter, diameter);

    // 画标签文字（灯右侧）
    painter.setPen(QColor("#ECF0F1"));
    QFont font = painter.font();
    font.setPointSize(9);
    painter.setFont(font);
    painter.drawText(QRect(diameter + 8, 0,
                           width() - diameter - 8, height()),
                     Qt::AlignVCenter | Qt::AlignLeft, m_label);
}
```

```cpp
void LevelBar::paintEvent(QPaintEvent* event)
{
    Q_UNUSED(event);

    QPainter painter(this);
    painter.setRenderHint(QPainter::Antialiasing);

    // 🎯 布局规划（自底向上）：
    //   顶部 20px：标题
    //   中间主体：柱体
    //   底部 24px：数值
    int title_h = 20;
    int value_h = 24;

    // 柱体区域（留出左侧 20px 画刻度）
    QRect bar_rect(22, title_h,
                   width() - 34, height() - title_h - value_h);
    if (bar_rect.height() < 10) return;  // 太小了不画

    // ---- 1. 画柱体背景（空的部分）----
    painter.setPen(QPen(QColor("#4A6278"), 1));
    painter.setBrush(QColor("#2C3E50"));
    painter.drawRect(bar_rect);

    // ---- 2. 画填充部分（液位）----
    if (m_valid) {
        // 计算填充高度比例
        double ratio = 0.0;
        if (m_max > m_min) {
            ratio = (m_value - m_min) / (m_max - m_min);
        }

        int fill_h = static_cast<int>(bar_rect.height() * ratio);

        // 🎯 注意 Qt 坐标系：y 轴向下！
        // 填充从柱体"底部"开始向上，所以 y 坐标是
        // bar_rect.bottom() - fill_h
        QRect fill_rect(bar_rect.left() + 1,
                        bar_rect.bottom() - fill_h,
                        bar_rect.width() - 1,
                        fill_h);

        // 颜色：超报警线变红，否则蓝色渐变
        QColor fill_color = (m_has_limit && m_value >= m_high_limit)
                            ? QColor("#E74C3C") : QColor("#3498DB");

        // 线性渐变：上浅下深，模拟液体
        QLinearGradient grad(fill_rect.topLeft(), fill_rect.bottomLeft());
        grad.setColorAt(0.0, fill_color.lighter(130));
        grad.setColorAt(1.0, fill_color.darker(110));

        painter.setPen(Qt::NoPen);
        painter.setBrush(grad);
        painter.drawRect(fill_rect);
    }

    // ---- 3. 画报警线 ----
    if (m_has_limit && m_max > m_min) {
        double limit_ratio = (m_high_limit - m_min) / (m_max - m_min);
        int limit_y = bar_rect.bottom()
                    - static_cast<int>(bar_rect.height() * limit_ratio);

        painter.setPen(QPen(QColor("#E74C3C"), 2, Qt::DashLine));  // 红虚线
        painter.drawLine(bar_rect.left() - 4, limit_y,
                         bar_rect.right() + 4, limit_y);
    }

    // ---- 4. 画刻度线（柱体左侧）----
    painter.setPen(QColor("#7F8C8D"));
    QFont font = painter.font();
    font.setPointSize(6);
    painter.setFont(font);

    for (int i = 0; i <= 4; ++i) {
        // 每 25% 一条刻度
        int y = bar_rect.bottom() - bar_rect.height() * i / 4;
        painter.drawLine(bar_rect.left() - 6, y, bar_rect.left(), y);

        double tick_value = m_min + (m_max - m_min) * i / 4.0;
        painter.drawText(QRect(0, y - 6, 18, 12),
                         Qt::AlignRight | Qt::AlignVCenter,
                         QString::number(static_cast<int>(tick_value)));
    }

    // ---- 5. 画标题（顶部）----
    painter.setPen(QColor("#BDC3C7"));
    font.setPointSize(8);
    font.setBold(true);
    painter.setFont(font);
    painter.drawText(QRect(0, 0, width(), title_h),
                     Qt::AlignCenter, m_title);

    // ---- 6. 画数值（底部）----
    font.setPointSize(9);
    painter.setFont(font);
    painter.setPen(QColor("#ECF0F1"));
    QString value_text = m_valid
        ? QString::number(m_value, 'f', 1) + m_unit
        : "---";
    painter.drawText(QRect(0, height() - value_h, width(), value_h),
                     Qt::AlignCenter, value_text);
}
```

1. Qt 坐标系 **y 轴向下**，所以液位填充要"从底向上算"：`bottom - fill_height`
2. `QLinearGradient` / `QRadialGradient` 让控件有立体感
3. `startTimer()` / `timerEvent()` 是 QWidget 自带的轻量定时器，适合做闪烁动画

## 第二章：实时数据表格（Model/View 实战）

### 2.0 预备知识：QAbstractTableModel 必须实现的三个函数

Qt 的表格 Model 是一个抽象类，你继承它之后必须实现至少三个函数：

```cpp
class MyModel : public QAbstractTableModel
{
    // 1. 告诉 View：一共有几行？
    int rowCount(const QModelIndex& parent) const override;

    // 2. 告诉 View：一共有几列？
    int columnCount(const QModelIndex& parent) const override;

    // 3. 告诉 View：某行某列显示什么？
    QVariant data(const QModelIndex& index, int role) const override;
};
```

**QModelIndex 是什么？** 它是"数据的地址"，包含行号、列号。View 问"第 3 行第 1 列是什么"时，给你一个 `index.row()==3, index.column()==1` 的 QModelIndex。

**role 是什么？** 同一个单元格可以有多种"角色"的数据：

```
Qt::DisplayRole    —— 显示的文字（"150.3"）
Qt::ForegroundRole —— 文字颜色（红色/绿色）
Qt::BackgroundRole —— 背景颜色
Qt::TextAlignmentRole —— 对齐方式（居中）
Qt::ToolTipRole    —— 鼠标悬停提示
```

View 会分别询问："这个单元格的 DisplayRole 是什么？""ForegroundRole 是什么？"我们在 data() 里根据 role 返回不同内容。

**文件路径：** `D:\QtProject\UCS\src\ui\TagTableModel.cpp`

```cpp
// ============================================================
// TagTableModel.cpp — 表格模型实现
// ============================================================
#include "TagTableModel.h"
#include "core/tag/TagManager.h"
#include "core/rtdb/RealTimeDB.h"
#include <QDateTime>
#include <QColor>

TagTableModel::TagTableModel(QObject* parent)
    : QAbstractTableModel(parent)
{
}

void TagTableModel::initialize()
{
    // 🎯 beginResetModel / endResetModel：
    // 告诉 View "整个模型的数据都要换了"，View 会完全重绘
    beginResetModel();

    m_rows.clear();
    m_row_index.clear();

    // 从 TagManager 取所有标签定义
    const auto& tags = TagManager::instance().allTags();
    int row = 0;
    for (const auto& tag : tags) {
        m_rows.push_back(tag->tag_name);
        m_row_index[tag->tag_name] = row;
        ++row;
    }

    endResetModel();

    // 🎯 连接 RealTimeDB 的信号
    // 任何一个测点值变化 → 更新模型中对应行
    connect(&RealTimeDB::instance(), &RealTimeDB::tagValueChanged,
            this, &TagTableModel::onTagValueChanged);
}

int TagTableModel::rowCount(const QModelIndex& parent) const
{
    // parent 无效时返回行数（这是顶层调用的约定）
    if (parent.isValid()) return 0;
    return static_cast<int>(m_rows.size());
}

int TagTableModel::columnCount(const QModelIndex& parent) const
{
    if (parent.isValid()) return 0;
    return 6;  // 6 列：位号/描述/数值/单位/质量/时间
}

QVariant TagTableModel::data(const QModelIndex& index, int role) const
{
    // 防御：索引越界直接返回空
    if (!index.isValid() ||
        index.row() < 0 ||
        index.row() >= static_cast<int>(m_rows.size())) {
        return QVariant();
    }

    // 找到这一行对应的位号
    const std::string& tag_name = m_rows[index.row()];

    // 从 RealTimeDB 取最新值
    TagDataPoint point;
    bool has_data = RealTimeDB::instance().getTagValue(tag_name, point);

    // ---- 按角色返回不同内容 ----
    switch (role) {
    case Qt::DisplayRole: {
        // 显示的文字
        switch (index.column()) {
        case 0: return QString::fromStdString(tag_name);
        case 1: {
            // 描述从 TagManager 取（RealTimeDB 的点可能没填）
            const auto* def = TagManager::instance().findTag(tag_name);
            return def ? QString::fromStdString(def->description) : "";
        }
        case 2: {
            if (!has_data) return "---";
            if (point.data_type == DataType::BOOL)
                return (point.scaled_value > 0.5) ? "ON" : "OFF";
            return QString::number(point.scaled_value, 'f', 1);
        }
        case 3: {
            const auto* def = TagManager::instance().findTag(tag_name);
            return def ? QString::fromStdString(def->unit) : "";
        }
        case 4:
            return has_data ? qualityText(point.quality) : "无数据";
        case 5: {
            if (!has_data) return "";
            QDateTime dt = QDateTime::fromMSecsSinceEpoch(
                static_cast<qint64>(point.timestamp_ms));
            return dt.toString("HH:mm:ss");
        }
        }
        break;
    }

    case Qt::ForegroundRole: {
        // 🎯 文字颜色：按质量状态着色
        // 数值列和质量列按状态变色
        if (index.column() == 2 || index.column() == 4) {
            if (!has_data) return QColor("#7F8C8D");
            return qualityColor(point.quality);
        }
        return QColor("#ECF0F1");  // 其他列统一浅色
    }

    case Qt::TextAlignmentRole:
        // 数值列右对齐（数字靠右更专业），其他左对齐
        if (index.column() == 2)
            return static_cast<int>(Qt::AlignRight | Qt::AlignVCenter);
        return static_cast<int>(Qt::AlignLeft | Qt::AlignVCenter);

    case Qt::ToolTipRole:
        // 鼠标悬停提示：显示完整信息
        if (has_data) {
            return QString("位号: %1\n原始值: %2\n时间: %3")
                .arg(QString::fromStdString(tag_name))
                .arg(point.raw_value)
                .arg(QDateTime::fromMSecsSinceEpoch(
                    static_cast<qint64>(point.timestamp_ms))
                    .toString("yyyy-MM-dd HH:mm:ss.zzz"));
        }
        break;
    }

    return QVariant();
}

QVariant TagTableModel::headerData(int section,

void TagTableModel::onTagValueChanged(const QString& tag_name)
{
    // 🎯 找到这个位号在第几行
    auto it = m_row_index.find(tag_name.toStdString());
    if (it == m_row_index.end()) return;

    int row = it->second;

    // 🎯 发出 dataChanged 信号
    // 告诉 View：第 row 行的第 0 列到第 5 列数据变了，请重绘
    // View 收到后只重绘这几个单元格，不会重绘整个表格
    QModelIndex top_left = createIndex(row, 0);
    QModelIndex bottom_right = createIndex(row, columnCount() - 1);
    emit dataChanged(top_left, bottom_right);
}

QString TagTableModel::qualityText(Quality q)
{
    switch (q) {
    case Quality::GOOD:               return "正常";
    case Quality::UNCERTAIN:          return "可疑";
    case Quality::BAD:                return "故障";
    case Quality::GOOD_LOCAL_OVERRIDE: return "手动";
    default:                          return "未知";
    }
}

QColor TagTableModel::qualityColor(Quality q)
{
    switch (q) {
    case Quality::GOOD:               return QColor("#2ECC71");  // 绿
    case Quality::UNCERTAIN:          return QColor("#F39C12");  // 黄
    case Quality::BAD:                return QColor("#E74C3C");  // 红
    case Quality::GOOD_LOCAL_OVERRIDE: return QColor("#3498DB"); // 蓝
    default:                          return QColor("#7F8C8D");
    }
}
```

**为什么 dataChanged 只传一行而不是整个表？**

如果每次值变化都重绘整个 200 行的表格，CPU 会被界面刷新拖垮。`emit dataChanged(top_left, bottom_right)` 精确告诉 View"只重绘这一个区域"，哪怕 10 个测点同时变化，也只有 10 行被重绘。

## 第三章：实时趋势曲线（QtCharts 实战）

### 3.0 预备知识：趋势曲线的两个设计决策

写趋势曲线之前，先想清楚两个问题：

**问题 1：X 轴用什么？**

- 选项 A：数据点序号（第 1 个点、第 2 个点...）——简单，但看不出时间跨度
- 选项 B：时间戳——用户能直接看到"这条曲线是最近 60 秒的"
- 我们选 B，用 `QDateTimeAxis`

**问题 2：Y 轴范围怎么定？**

- 选项 A：固定量程（温度固定 0-300）——稳定，但数值在 25-30 之间时曲线像直线
- 选项 B：自动适应当前数据范围——曲线始终充满视图，但 Y 轴一直在变
- 我们选 B 加"最小跨度保护"（范围小于 10 时按 10 显示，防止噪声放大）

**数据来源：** RealTimeDB 的 `getTagHistory(tag, 600)`——每个测点的 RingBuffer 里保存了最近 600 个点（100ms 一个，正好 60 秒）。

```cpp
    // 初始 X 轴范围：当前时间往前 60 秒
    QDateTime now = QDateTime::currentDateTime();
    m_axis_x->setRange(now.addSecs(-WINDOW_SECONDS), now);

    // 初始 Y 轴范围
    m_axis_y->setRange(0, 100);

    // 把图表装到视图里
    m_chart_view->setChart(m_chart);
}

void RealTimeTrend::onAddSeries()
{
    // 从下拉框取选中的位号（存在 userData 里的纯位号）
    QString tag_name = m_tag_combo->currentData().toString();
    if (tag_name.isEmpty()) return;

    addSeriesForTag(tag_name);
}

void RealTimeTrend::addSeriesForTag(const QString& tag_name)
{
    // 已存在该曲线则不重复添加
    if (m_series_map.contains(tag_name)) {
        LOG_DEBUG("RealTimeTrend: series for {} already exists",
                  tag_name.toStdString());
        return;
    }

    // 最多 3 条曲线（颜色池就 3 个颜色）
    if (m_series_map.size() >= s_color_pool.size()) {
        LOG_WARN("RealTimeTrend: max {} series allowed",
                 s_color_pool.size());
        return;
    }

    // ---- 创建折线 ----
    auto* series = new QLineSeries();
    series->setName(tag_name);

    // 分配颜色
    QColor color = s_color_pool.at(m_series_map.size());
    QPen pen(color, 2);
    series->setPen(pen);

    // 🎯 关键：把 series 加入 chart，然后绑定坐标轴
    // 顺序不能反——必须先 addSeries，再 attachAxis
    m_chart->addSeries(series);
    series->attachAxis(m_axis_x);
    series->attachAxis(m_axis_y);

    m_series_map.insert(tag_name, series);
    LOG_INFO("RealTimeTrend: added series for {}", tag_name.toStdString());
}

void RealTimeTrend::onClearSeries()
{
    // removeAllSeries 会删除 chart 中所有 series 对象
    m_chart->removeAllSeries();
    m_series_map.clear();
}

void RealTimeTrend::refreshChart()
{
    if (m_series_map.isEmpty()) return;

    updateAllSeries();

    // X 轴跟随当前时间滚动
    QDateTime now = QDateTime::currentDateTime();
    m_axis_x->setRange(now.addSecs(-WINDOW_SECONDS), now);

    autoScaleYAxis();
}

void RealTimeTrend::updateAllSeries()
{
    auto& rtdb = RealTimeDB::instance();

    for (auto it = m_series_map.begin(); it != m_series_map.end(); ++it) {
        const QString& tag_name = it.key();
        QLineSeries* series = it.value();

        // 🎯 从 RingBuffer 取最近 60 秒的历史数据
        auto history = rtdb.getTagHistory(tag_name.toStdString(), MAX_POINTS);
        if (history.empty()) continue;

        // 🎯 性能要点：一次性替换全部数据
        // 不要一个点一个点 append（每次都会触发图表重绘），
        // 而是构建 QVector 后调用 replace()，一次重绘完成。
        QVector<QPointF> points;
        points.reserve(static_cast<int>(history.size()));

        for (const auto& point : history) {
            // QDateTimeAxis 的 X 值是"毫秒时间戳"（以 double 存储）
            points.append(QPointF(
                static_cast<double>(point.timestamp_ms),
                point.scaled_value));
        }

        series->replace(points);

        // 更新图例显示当前值
        if (!history.empty()) {
            series->setName(QString("%1: %2")
                .arg(tag_name)
                .arg(history.back().scaled_value, 0, 'f', 1));
        }
    }
}

void RealTimeTrend::autoScaleYAxis()
{
    // 遍历所有曲线，找出全局最大/最小值
    double global_min = std::numeric_limits<double>::max();
    double global_max = std::numeric_limits<double>::lowest();

    for (auto* series : m_series_map) {
        const auto& points = series->points();
        for (const auto& p : points) {
            global_min = qMin(global_min, p.y());
            global_max = qMax(global_max, p.y());
        }
    }

    // 没有数据时保持默认范围
    if (global_min > global_max) {
        m_axis_y->setRange(0, 100);
        return;
    }

    // 🎯 加 10% 边距，曲线不会贴边
    double margin = (global_max - global_min) * 0.1;

    // 最小跨度保护：防止噪声被放大成"剧烈波动"
    if (global_max - global_min < 10.0) {
        double center = (global_max + global_min) / 2.0;
        global_min = center - 5.0;
        global_max = center + 5.0;
    } else {
        global_min -= margin;
        global_max += margin;
    }

    m_axis_y->setRange(global_min, global_max);
}
```

**性能要点总结：**

| 做法                        | 为什么                                  |
| ------------------------- | ------------------------------------ |
| `series->replace(points)` | 一次替换全部数据，只触发一次重绘                     |
| 最多 600 点/曲线               | 100ms × 600 = 60 秒，与 RingBuffer 容量匹配 |
| 500ms 刷新间隔                | 每次刷新包含 5 个新点，看起来流畅且省 CPU             |
| `NoAnimation`             | 实时数据不要动画，动画反而拖慢                      |

## 第四章：工艺流程图 P&ID（QGraphicsView 实战）

### 4.0 预备知识：场景搭建的三个层次

工艺流程图是本阶段最复杂的模块。先理清三个概念：

**QGraphicsItem（图元）** ——场景里的"一个东西"。每个设备（釜、阀、泵、管道）都是一个图元。它必须实现两个函数：

```cpp
class ValveItem : public QGraphicsItem
{
    // 1. boundingRect()：告诉场景"我占多大地方"
    //    用于碰撞检测、重绘区域判断
    QRectF boundingRect() const override;

    // 2. paint()：画出自己
    //    参数 painter 已经设置好坐标系（原点在图元自己的中心）
    void paint(QPainter* painter,
               const QStyleOptionGraphicsItem* option,
               QWidget* widget) override;
};
```

**QGraphicsScene（场景）** ——所有图元的"家"。图元通过 `scene->addItem(item)` 放进去。场景负责：图元管理、鼠标事件分发、重绘调度。

**QGraphicsView（视图）** ——观察场景的"窗口"。支持：

- `scale(1.2, 1.2)` 缩放
- `setDragMode(ScrollHandDrag)` 鼠标拖动平移
- 滚轮缩放（需要自己写 wheelEvent）

**坐标系（重点理解）：**

```
场景坐标：整个虚拟画布的坐标（比如釜在 (300, 200)）
图元坐标：每个图元内部的坐标（比如阀门图元的中心是 (0,0)）
视图坐标：屏幕像素坐标

图元被 addItem 后通过 setPos(300, 200) 放到场景的 (300,200)
paint() 里画图时用的永远是"图元坐标"——
你只管以自己为中心画，场景框架负责把你摆到正确位置
```

### 4.1 整体结构设计

```
ProcessView（QGraphicsView 子类）
    │ 负责：缩放、平移、定时刷新数据
    │
    └── QGraphicsScene
          │
          ├── ReactorItem    —— 反应釜（显示液位填充）
```

### 4.2 写 ValveItem（阀门图元）

**文件路径：** `D:\QtProject\UCS\src\ui\process\ValveItem.h`

```cpp
// ============================================================
// ValveItem.h — 阀门图元
//
// 阀门画成两个对顶的三角形（蝶阀的标准画法）：
//      ◁▷
// 状态：
//   开 → 绿色
//   关 → 红色
//   故障 → 灰色闪烁
// ============================================================
#pragma once

#include <QGraphicsItem>
#include <QString>

class ValveItem : public QGraphicsItem

    QString m_tag_name;   // 绑定的测点位号
    QString m_label;      // 显示文字
    bool m_open = false;  // 当前开关状态

    // 阀门尺寸（图元坐标系下）
    static constexpr qreal VALVE_WIDTH = 30;
    static constexpr qreal VALVE_HEIGHT = 20;
```

**文件路径：** `D:\QtProject\UCS\src\ui\process\ValveItem.cpp`

```cpp
// ============================================================
// ValveItem.cpp — 阀门图元实现
// ============================================================
#include "ValveItem.h"
#include <QPainter>

ValveItem::ValveItem(const QString& tag_name)
    : m_tag_name(tag_name)
    , m_label(tag_name)
{
    // 🎯 启用缓存模式：图元内容不变时，Qt 会把 paint 结果
    // 缓存成位图，下次直接贴图，大幅提升性能
    // 状态变化时我们调用 update() 强制重绘
    setCacheMode(DeviceCoordinateCache);

    // 允许接收鼠标悬浮事件（显示提示用）
    setAcceptHoverEvents(true);
    setToolTip(QString("阀门 %1").arg(tag_name));
}

QRectF ValveItem::boundingRect() const
{
    // 返回图元的"包围盒"——场景用它判断哪些图元需要重绘
    // 要比实际图形稍大（留出标签文字和描边的空间）
    return QRectF(-VALVE_WIDTH / 2 - 5,
                  -VALVE_HEIGHT / 2 - 5,
                  VALVE_WIDTH + 10,
                  VALVE_HEIGHT + 30);   // 下方留标签位置
}

void ValveItem::paint(QPainter* painter,
                      const QStyleOptionGraphicsItem* option,
                      QWidget* widget)
{
    Q_UNUSED(option);
    Q_UNUSED(widget);

    painter->setRenderHint(QPainter::Antialiasing);

    // 🎯 颜色由状态决定
    QColor color = m_open ? QColor("#2ECC71")   // 开=绿
                          : QColor("#E74C3C");  // 关=红

    painter->setPen(QPen(color.darker(130), 2));
    painter.setBrush(color);

    // 🎯 阀门画法：两个对顶的三角形（蝶阀标准符号）
    //
    //    (-w/2, -h/2) 左上        (w/2, -h/2) 右上
    //         ╲                    ╱
    //          ╲                  ╱
    //           ╲                ╱
    //            (0,0) 中心交点
    //           ╱                ╲
    //          ╱                  ╲
    //    (-w/2, h/2) 左下        (w/2, h/2) 右下
    //
    // 左三角：(左上) → (左下) → (中心)
    // 右三角：(右上) → (右下) → (中心)

    qreal w = VALVE_WIDTH / 2;
    qreal h = VALVE_HEIGHT / 2;

    QPolygonF left_triangle;
    left_triangle << QPointF(-w, -h)
                  << QPointF(-w, h)
                  << QPointF(0, 0);
    painter->drawPolygon(left_triangle);

    QPolygonF right_triangle;
    right_triangle << QPointF(w, -h)
                   << QPointF(w, h)
                   << QPointF(0, 0);
    painter->drawPolygon(right_triangle);

    // 画位号文字（阀门下方）
    painter->setPen(QColor("#ECF0F1"));
    QFont font = painter->font();
    font.setPointSize(6);
    painter->setFont(font);
    painter->drawText(QRectF(-30, h + 2, 60, 14),
                      Qt::AlignCenter, m_label);
}

void ValveItem::setOpen(bool open)
{
    if (m_open != open) {
        m_open = open;
        update();   // 状态变了，通知场景重绘这个图元
    }
}

void ValveItem::setLabel(const QString& text)
{
    m_label = text;
    update();
}

QString ValveItem::tagName() const
{
    return m_tag_name;
}
```

**🎯 为什么 setOpen 里要判断 `if (m_open != open)`？**

避免不必要的重绘。仿真数据每 100ms 来一次，如果阀门状态没变就调用 update()，会导致场景每 100ms 重绘一次阀门——白白浪费 CPU。只有状态真的变了才重绘。

### 4.3 写 ReactorItem（反应釜图元）

**文件路径：** `D:\QtProject\UCS\src\ui\process\ReactorItem.cpp`

```cpp
// ============================================================
// ReactorItem.cpp — 反应釜图元实现
// ============================================================
#include "ReactorItem.h"
#include <QPainter>
#include <QGraphicsSceneHoverEvent>
#include <QToolTip>

ReactorItem::ReactorItem()
{
    setCacheMode(DeviceCoordinateCache);
    setAcceptHoverEvents(true);
    setToolTip("反应釜 R-101");
}

QRectF ReactorItem::boundingRect() const
{
    // 包围盒：釜体 + 上方阶段文字 + 下方温度显示
    return QRectF(-BODY_WIDTH / 2 - 10,
                  -BODY_HEIGHT / 2 - 30,
                  BODY_WIDTH + 20,
                  BODY_HEIGHT + 70);
}

void ReactorItem::paint(QPainter* painter,
                        const QStyleOptionGraphicsItem* option,
                        QWidget* widget)
{
    Q_UNUSED(option);
    Q_UNUSED(widget);

    painter->setRenderHint(QPainter::Antialiasing);

    qreal w = BODY_WIDTH;
    qreal h = BODY_HEIGHT;
    qreal x = -w / 2;
    qreal y = -h / 2;

    // ---- 1. 画釜体外壁（圆角矩形 + 金属渐变）----
    QLinearGradient body_grad(x, 0, x + w, 0);
    body_grad.setColorAt(0.0, QColor("#5D6D7E"));   // 左侧暗
    body_grad.setColorAt(0.5, QColor("#85929E"));   // 中间亮（圆柱反光）
    body_grad.setColorAt(1.0, QColor("#5D6D7E"));   // 右侧暗

    painter->setPen(QPen(QColor("#34495E"), 3));
    painter.setBrush(body_grad);
    painter->drawRoundedRect(QRectF(x, y, w, h), 20, 20);  // 圆角半径 20

    // ---- 2. 画液位填充（内壁裁剪 + 蓝色填充）----
    // 🎯 技巧：用 setClipRect 限制填充只在釜体内部
    // 防止液体"溢出"到釜壁外面
    painter->save();  // 保存状态（裁剪设置也会被保存）

    // 裁剪区域：釜体内壁（比外壁小一圈，留出壁厚）
    QRectF inner_rect(x + 4, y + 4, w - 8, h - 8);
    painter->setClipRect(inner_rect);

    // 计算液位高度
    double level_ratio = qBound(0.0, m_level / 100.0, 1.0);
    qreal fill_h = inner_rect.height() * level_ratio;

    if (fill_h > 0) {
        // 液体颜色：温度高时偏红（加热提示），正常蓝色
        QColor liquid_color;
        if (m_temperature > 120.0) {
            liquid_color = QColor("#E67E22");   // 橙（高温）
        } else {
            liquid_color = QColor("#3498DB");   // 蓝（常温）
        }

        // 液体渐变：上浅下深
        QLinearGradient liquid_grad(0, inner_rect.bottom() - fill_h,
                                    0, inner_rect.bottom());
        liquid_grad.setColorAt(0.0, liquid_color.lighter(130));
        liquid_grad.setColorAt(1.0, liquid_color.darker(120));

        painter->setPen(Qt::NoPen);
        painter->setBrush(liquid_grad);
        painter->drawRect(QRectF(inner_rect.left(),
                                 inner_rect.bottom() - fill_h,
                                 inner_rect.width(),
                                 fill_h));

        // 液面线（白色细线）
        painter->setPen(QPen(QColor(255, 255, 255, 180), 1));
        painter->drawLine(QPointF(inner_rect.left(),
                                  inner_rect.bottom() - fill_h),
                          QPointF(inner_rect.right(),
                                  inner_rect.bottom() - fill_h));
    }

    painter->restore();  // 恢复状态（解除裁剪）

    // ---- 3. 画搅拌器（如果运行）----
    if (m_agitator_running) {
        painter->setPen(QPen(QColor(255, 255, 255, 150), 3));
        // 搅拌轴：从顶部中央向下
        painter->drawLine(QPointF(0, y + 10), QPointF(0, y + h * 0.6));
        // 搅拌桨：底部横线
        painter->drawLine(QPointF(-25, y + h * 0.6),
                          QPointF(25, y + h * 0.6));
    }

    // ---- 4. 画内部数值（温度、压力）----
    painter->setPen(QColor("#FFFFFF"));
    QFont font = painter->font();
    font.setPointSize(7);
    font.setBold(true);
    painter->setFont(font);

    painter->drawText(QRectF(x + 5, y + 15, w - 10, 16),
                      Qt::AlignCenter,
                      QString("%1°C").arg(m_temperature, 0, 'f', 1));
    painter->drawText(QRectF(x + 5, y + 32, w - 10, 16),
                      Qt::AlignCenter,
                      QString("%1 MPa").arg(m_pressure, 0, 'f', 2));

    // 液位百分比（釜体中部）
    font.setPointSize(9);
    painter->setFont(font);
    painter->drawText(QRectF(x, y + h * 0.4, w, 20),
                      Qt::AlignCenter,
                      QString("%1%").arg(m_level, 0, 'f', 1));

    // ---- 5. 画工艺阶段文字（釜体上方）----
    font.setPointSize(8);
    painter->setFont(font);
    painter->setPen(QColor("#F39C12"));   // 橙色高亮
    painter->drawText(QRectF(x, y - 24, w, 18),
                      Qt::AlignCenter, m_stage_text);
}
```

```cpp
#include <QPainter>

    , m_to(to)

QRectF PipeItem::boundingRect() const
{
    // 管道是 from → to 的线段，包围盒就是两点的外接矩形
    // 加 10px 边距容纳线宽

void PipeItem::paint(QPainter* painter,
                     const QStyleOptionGraphicsItem* option,
                     QWidget* widget)
{
    Q_UNUSED(option);
    Q_UNUSED(widget);

    if (m_flowing) {
        // 🎯 流动状态：蓝色虚线 + 偏移动画
        QPen pen(QColor("#3498DB"), 4);
        pen.setStyle(Qt::DashLine);          // 虚线
        pen.setDashOffset(m_dash_offset);    // 偏移量（动画关键）
        pen.setCapStyle(Qt::RoundCap);
        painter->setPen(pen);
    } else {
        // 静止状态：灰色实线
        painter->setPen(QPen(QColor("#5D6D7E"), 4));
    }

    painter->drawLine(m_from, m_to);
}

{
    if (m_flowing != flowing) {
        m_flowing = flowing;
        update();
    }
}

void PipeItem::advanceAnimation()
{
    if (!m_flowing) return;

    // 🎯 偏移量递增，虚线段"向前移动"
    // 每调用一次移动 1 像素，配合 50ms 定时器 = 20 px/s 流速
    m_dash_offset += 1.0;

    // 偏移量超过虚线周期（dash 默认 4px 线 + 4px 空 = 8px 周期）
    // 就归零，形成无缝循环
    if (m_dash_offset > 8.0) {
        m_dash_offset = 0.0;
    }

    update();
}
```

## 第五章：历史数据存储与查询

### 5.0 预备知识：历史数据的三个设计决策

**决策 1：存什么？**

不可能每个 100ms 的点都存（一天 864,000 条/测点）。常见策略：

- **快照存储**：每 5 秒存一次当前值 → 一天 17,280 条/测点，可接受
- **死区压缩**：数值变化超过阈值才存 → 平稳时几乎不存
- **聚合存储**：每分钟存一条（平均值）→ 长期趋势用

我们实现"快照 + 死区"的混合：每 5 秒强制存一次，中间如果变化超过 2% 也存。

**决策 2：表怎么分？**

```
方案 A：一张大表 data_history，永远往里插
方案 B：按月分表 data_202607、data_202608...
```

选 B。原因：查询时 SQLite 只需要扫描当月的小表，删除旧数据直接 `DROP TABLE` 整个删（比 `DELETE FROM` 快几百倍）。

**决策 3：哪个线程写库？**

数据采集在主线程（SimEngine 的 QTimer），如果写库也在主线程，SQLite 写入慢时会卡 UI。但第一阶段的架构都在主线程，为了简化，我们用**批量写入**缓解：攒 50 条数据，用事务一次性写入（事务能把 50 次写入的开销降到接近 1 次）。

**SQLite 事务的概念：** 事务是"一组操作的打包"。没有事务时，每条 INSERT 都要写一次磁盘；用事务包起来，50 条 INSERT 只在事务提交时写一次磁盘。性能差距可达 100 倍。

```cpp
    // 死区压缩：记录每个测点"上次存储的值"
    std::unordered_map<std::string, double> m_last_stored;
    double m_deadband_percent = 2.0;   // 死区阈值 2%

    bool m_initialized = false;
```

```cpp
bool HistoryDB::initialize(const QString& db_path)
{
    // 确保目录存在
    QDir dir = QFileInfo(db_path).absoluteDir();
    if (!dir.exists()) {
        dir.mkpath(".");
    }

    // 🎯 QtSql 连接 SQLite
    // QSQLITE 是 Qt 内置驱动名，不需要安装任何东西
    m_db = QSqlDatabase::addDatabase("QSQLITE", "history_connection");
    m_db.setDatabaseName(db_path);

    if (!m_db.open()) {
        LOG_ERROR("HistoryDB: failed to open database - {}",
                  m_db.lastError().text().toStdString());
        return false;
    }

    // 🎯 SQLite 性能优化：WAL 模式
    // WAL（Write-Ahead Logging）让读写可以并发，
    // 写库时不会锁住查询，上位机场景必备
    QSqlQuery pragma(m_db);
    pragma.exec("PRAGMA journal_mode=WAL");
    pragma.exec("PRAGMA synchronous=NORMAL");  // 适当牺牲持久性换速度

    m_initialized = true;
    LOG_INFO("HistoryDB: initialized at {}", db_path.toStdString());
    return true;
}

QString HistoryDB::ensureMonthTable(qint64 timestamp_ms)
{
    // 根据时间戳生成表名：data_202607
    QDateTime dt = QDateTime::fromMSecsSinceEpoch(timestamp_ms);
    QString table_name = QString("data_%1")
        .arg(dt.toString("yyyyMM"));

    // 🎯 检查表是否存在，不存在则创建
    // CREATE TABLE IF NOT EXISTS：SQLite 的原子操作，
    // 表已存在时什么也不做，所以每次调用都是安全的
    QSqlQuery query(m_db);
    QString sql = QString(
        "CREATE TABLE IF NOT EXISTS %1 ("
        "  id INTEGER PRIMARY KEY AUTOINCREMENT,"
        "  tag_name TEXT NOT NULL,"
        "  value REAL NOT NULL,"
        "  quality INTEGER DEFAULT 192,"
        "  timestamp_ms INTEGER NOT NULL"
        ")").arg(table_name);

    if (!query.exec(sql)) {
        LOG_ERROR("HistoryDB: create table failed - {}",
                  query.lastError().text().toStdString());
    }

    // 创建复合索引（tag_name + timestamp_ms）
    // 查询都是"某测点在某时间段"，这个索引刚好覆盖
    QString index_sql = QString(
        "CREATE INDEX IF NOT EXISTS idx_%1_tagtime "
        "ON %1(tag_name, timestamp_ms)").arg(table_name);
    query.exec(index_sql);

    return table_name;
}

void HistoryDB::startSnapshot(int interval_ms)
{
    if (!m_initialized) return;

    if (!m_snapshot_timer) {
        m_snapshot_timer = new QTimer(this);
        connect(m_snapshot_timer, &QTimer::timeout,
                this, &HistoryDB::onSnapshotTimer);
    }
    m_snapshot_timer->start(interval_ms);
    LOG_INFO("HistoryDB: snapshot started (interval={}ms)", interval_ms);
}

void HistoryDB::stopSnapshot()
{
    if (m_snapshot_timer) {
        m_snapshot_timer->stop();
    }
    // 停止前把缓冲里剩余的数据写完
    flushBuffer();
}

void HistoryDB::onSnapshotTimer()
{
    // 🎯 定时快照：把 RealTimeDB 中所有测点的当前值存入缓冲
    auto all_values = RealTimeDB::instance().getAllLatestValues();

    for (const auto& point : all_values) {
        // 死区压缩判断
        if (!shouldStore(point.tag_name, point.scaled_value)) {
            continue;
        }

        PendingRecord rec;
        rec.tag_name = point.tag_name;
        rec.value = point.scaled_value;
        rec.quality = static_cast<int>(point.quality);
        rec.timestamp_ms = static_cast<qint64>(point.timestamp_ms);
        m_buffer.push_back(rec);

        // 更新"上次存储值"
        m_last_stored[point.tag_name] = point.scaled_value;
    }

    // 缓冲够了就批量写入
    if (m_buffer.size() >= FLUSH_THRESHOLD) {
        flushBuffer();
    }
}

bool HistoryDB::shouldStore(const std::string& tag_name, double value)
{
    // 🎯 死区压缩：与上次存储值比较
    // 变化超过 deadband_percent% 才值得存
    auto it = m_last_stored.find(tag_name);
    if (it == m_last_stored.end()) {
        return true;  // 第一次，必须存
    }

    double last = it->second;
    if (last == 0.0) {
        return value != 0.0;
    }

    double change_percent = qAbs(value - last) / qAbs(last) * 100.0;
    return change_percent >= m_deadband_percent;
}

void HistoryDB::flushBuffer()
{
    if (m_buffer.empty() || !m_initialized) return;

    // 🎯 事务批量写入
    // transaction() 开始事务，commit() 提交
    // 中间的 INSERT 都在内存中排队，提交时一次写盘
    m_db.transaction();

    // 按时间分表写入
    // 注意：缓冲里的数据可能跨月（不太可能但要处理），
    // 所以每条记录单独确定表名
    for (const auto& rec : m_buffer) {
        QString table = ensureMonthTable(rec.timestamp_ms);

        QSqlQuery query(m_db);
        query.prepare(QString(
            "INSERT INTO %1 (tag_name, value, quality, timestamp_ms) "
            "VALUES (:tag, :val, :qua, :ts)").arg(table));

        // 🎯 参数绑定：比字符串拼接安全（防 SQL 注入）且更快
        query.bindValue(":tag", QString::fromStdString(rec.tag_name));
        query.bindValue(":val", rec.value);
        query.bindValue(":qua", rec.quality);
        query.bindValue(":ts", rec.timestamp_ms);

        if (!query.exec()) {
            LOG_ERROR("HistoryDB: insert failed - {}",
                      query.lastError().text().toStdString());
        }
    }

    m_db.commit();

    LOG_DEBUG("HistoryDB: flushed {} records", m_buffer.size());
    m_buffer.clear();
}

std::vector<HistoryRecord> HistoryDB::queryHistory(
    const std::string& tag_name,
    qint64 start_ms,
    qint64 end_ms,
    int max_rows)
{
    std::vector<HistoryRecord> result;
    if (!m_initialized) return result;

    // 🎯 确定查询涉及哪些月份的表
    // 简化处理：用开始时间的月份（跨月查询作为扩展练习）
    QString table = QString("data_%1")
        .arg(QDateTime::fromMSecsSinceEpoch(start_ms).toString("yyyyMM"));

    // 检查表是否存在
    QSqlQuery check(m_db);
    check.exec(QString(
        "SELECT name FROM sqlite_master WHERE type='table' AND name='%1'"
        ).arg(table));
    if (!check.next()) {
        return result;  // 表不存在，返回空
    }

    // 🎯 查询 + 降采样
    // 如果时间段内的数据超过 max_rows，按比例抽样
    // 简化实现：直接用 LIMIT（更精确的降采样可用时间分桶聚合）
    QSqlQuery query(m_db);
    query.prepare(QString(
        "SELECT tag_name, value, quality, timestamp_ms "
        "FROM %1 "
        "WHERE tag_name = :tag "
        "  AND timestamp_ms >= :start "
        "  AND timestamp_ms <= :end "
        "ORDER BY timestamp_ms ASC "
        "LIMIT :limit").arg(table));

    query.bindValue(":tag", QString::fromStdString(tag_name));
    query.bindValue(":start", start_ms);
    query.bindValue(":end", end_ms);
    query.bindValue(":limit", max_rows);

    if (!query.exec()) {
        LOG_ERROR("HistoryDB: query failed - {}",
                  query.lastError().text().toStdString());
        return result;
    }

    while (query.next()) {
        HistoryRecord rec;
        rec.tag_name = query.value(0).toString().toStdString();
        rec.value = query.value(1).toDouble();
        rec.quality = query.value(2).toInt();
        rec.timestamp_ms = query.value(3).toLongLong();
        result.push_back(rec);
    }

    LOG_DEBUG("HistoryDB: query {} returned {} rows",
              tag_name, result.size());
    return result;
}

bool HistoryDB::exportToCsv(const std::vector<HistoryRecord>& records,
                             const QString& file_path)
{
    QFile file(file_path);
    if (!file.open(QIODevice::WriteOnly | QIODevice::Text)) {
        LOG_ERROR("HistoryDB: cannot open CSV file - {}",
                  file_path.toStdString());
        return false;
    }

    QTextStream out(&file);

    // 写表头
    out << "timestamp,datetime,tag_name,value,quality\n";

    // 写数据行
    for (const auto& rec : records) {
        QDateTime dt = QDateTime::fromMSecsSinceEpoch(rec.timestamp_ms);
        out << rec.timestamp_ms << ","
            << dt.toString("yyyy-MM-dd HH:mm:ss") << ","
            << QString::fromStdString(rec.tag_name) << ","
            << rec.value << ","
            << rec.quality << "\n";
    }

    file.close();
    LOG_INFO("HistoryDB: exported {} records to {}",
             records.size(), file_path.toStdString());
    return true;
}
```

```cpp
void HistoryTrend::onQuery()
{
    QString tag_name = m_tag_combo->currentText();
    if (tag_name.isEmpty()) return;

    qint64 start_ms = m_start_edit->dateTime().toMSecsSinceEpoch();
    qint64 end_ms = m_end_edit->dateTime().toMSecsSinceEpoch();

    if (start_ms >= end_ms) {
        QMessageBox::warning(this, "时间错误",
                             "开始时间必须早于结束时间");
        return;
    }

    // ---- 查询数据库 ----
    auto records = HistoryDB::instance().queryHistory(
        tag_name.toStdString(), start_ms, end_ms);

    if (records.empty()) {
        QMessageBox::information(this, "无数据",
            "该时间段内没有历史数据。\n请确认历史存储已启动且时间范围内有数据。");
        return;
    }

    // ---- 填充曲线 ----
    QVector<QPointF> points;
    points.reserve(static_cast<int>(records.size()));
    for (const auto& rec : records) {
        points.append(QPointF(
            static_cast<double>(rec.timestamp_ms), rec.value));
    }
    m_series->replace(points);
    m_series->setName(tag_name);

    // ---- 调整坐标轴 ----
    m_axis_x->setRange(m_start_edit->dateTime(), m_end_edit->dateTime());

    // Y 轴自适应
    double min_val = std::numeric_limits<double>::max();
    double max_val = std::numeric_limits<double>::lowest();
    for (const auto& rec : records) {
        min_val = qMin(min_val, rec.value);
        max_val = qMax(max_val, rec.value);
    }
    double margin = (max_val - min_val) * 0.1 + 1.0;
    m_axis_y->setRange(min_val - margin, max_val + margin);

    m_chart->setTitle(QString("历史趋势 — %1 (%2 条记录)")
                          .arg(tag_name)
                          .arg(records.size()));
}
```
